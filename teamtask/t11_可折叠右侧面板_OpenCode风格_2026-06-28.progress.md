# Progress Log — 可折叠右侧面板（OpenCode 风格）

## Session: 2026-06-28

### Phase 1: Requirements & Discovery
- **Status:** complete
- 理解用户意图：可折叠、斜杠/快捷键调出、task/todo + worker + 当前计划 + metrics。

### Phase 2: Design & Interface
- **Status:** complete
- 确定默认折叠、宽度 32、快捷键 `]` / `ctrl+x r`、斜杠 `/panel [on|off]`。
- 确定 section：Current Tool、Tasks、Workers、Current Plan、Metrics、Shortcuts。

### Phase 3: Implementation
- **Status:** complete
- `src/prompt/engine.ts`: 新增 `getActivePlanPointer()` getter。
- `src/tui/engine/input-handler.ts`: 新增 `ctrl_x` 键名映射。
- `src/tui/engine/app.ts`:
  - `SIDE_PANEL_WIDTH` 28 → 32。
  - `TuiState` 新增 `sidePanelOpen`（默认 `false`）。
  - 新增 `activePlanProvider`、`setActivePlanProvider()`、`toggleSidePanel()`、`setSidePanelOpen()`、`isSidePanelOpen()`。
  - 注册内置 `/panel` 命令。
  - `onAnyKey` 增加 `]` toggle、`ctrl+x r` leader-key 打开面板。
  - `renderLive()` 按 `sidePanelOpen && columns >= 120` 控制渲染。
- `src/tui/side-panel.ts`: section-based 重构，复用 `formatTaskList`，新增 Current Plan 解析与 Shortcuts hint。
- `src/tui/format/task-list.ts`: 新增 `showProgressBar` 选项，侧栏使用 `showProgressBar: false` 的 Claude Code 风格紧凑标题 `◇ 任务 (done/total)`。
- `src/tui/engine/app.ts`: 主会话区任务列表同样使用 `showProgressBar: false`，并在任务列表与输入框顶部边框之间插入空行作为边界。
- `src/tui/engine/app.ts`: side panel 快捷键由裸 `]` 改为 `Ctrl+]`，避免用户输入 `]` 被劫持。
- `src/tui/engine/input-handler.ts`: 新增 `ctrl_]` 键名与 ASCII `0x1d` 映射。
- `src/tui/side-panel.ts`: 布局与截断统一改用 `displayWidth({ ambiguousAsWide: true })` 和 `truncateToDisplayWidth`，与 LiveEngine 口径一致；修复 `pad()` 直接 `.slice()` 截断 ANSI 字符串的问题；快捷键提示同步改为 `ctrl+] toggle · ctrl+x r`。
- `src/tui/engine/input-handler.ts`: 重构输入缓冲逻辑，引入 `inputBuffer` 与 `processInputBuffer()`，解决 ESC 序列整段吞掉（`\x1B[A\x1B[B` 等）和 bracketed paste 起止标记跨 chunk 识别失败的问题；新增 4 项回归测试。
- `src/tui/engine/stream-renderer.ts`: `getLiveTailLines` 改用 `capLiveTailMarkdownSafe`，避免 live tail 从代码块中间开始时把后续 prose 框进 stray code block；新增回归测试。
- `src/main.ts`: 接入 `setActivePlanProvider()`。
