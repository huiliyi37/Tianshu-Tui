# Findings & Decisions — 可折叠右侧面板（OpenCode 风格）

## Requirements

- 做一个可折叠的右侧面板，类似 OpenCode 的 overview/steering panel。
- 调出方式：斜杠命令 + 快捷键。
- 面板内容：task 列表 / todo、可展示的附加信息。
- 先出设计方案，不直接编码。

## Research Findings

### 竞品参考

- **OpenCode TUI**：使用 `ctrl+x` 作为 leader key，社区在请求 `ctrl+x r` 切换右侧面板（issue #19388）。
- **OpenAI Codex issue #16680**：用户明确提到 OpenCode 右侧面板对长任务和子代理的可视化价值，包含 MCP server、已完成/未完成任务列表。
- **Claude Code**：三态 checklist（☐ pending / ◐ in_progress / ☒ completed），已完成项折叠，保证活跃任务可见。

### 仓库现状

- 已有右侧持久面板：`src/tui/side-panel.ts`。
- 触发阈值：`SIDE_PANEL_MIN_COLUMNS = 120`，宽度 `SIDE_PANEL_WIDTH = 28`。
- 当前内容：星域/模型、token 仪表、当前工具、worker 舰队、简化 todo、缓存命中率。
- `src/tui/format/task-list.ts` 已提供更精致的 Claude Code 风格任务列表组件（进度条、三态、折叠已完成）。
- `renderLive()` 已修复 overlay 激活时重复绘制 side panel 的回归。

### 相关文件

- `src/tui/engine/app.ts` — 主 TUI 渲染循环、`mergeSidePanel()`、`renderLive()`。
- `src/tui/side-panel.ts` — 纯函数面板渲染。
- `src/tui/format/task-list.ts` — 任务列表格式化。
- `src/tui/fleet-registry.ts` — worker 舰队数据。
- `src/tui/slash-commands.ts` — 斜杠命令注册。
- `src/tui/engine/input-handler.ts` / `input-controller-state.ts` — 快捷键绑定。
- `src/tui/theme.ts` — 主题颜色。

## Technical Decisions

| Decision | Rationale |
|----------|-----------|
| 保持面板为"可折叠"而非"常驻" | 用户明确要求可折叠，避免窄屏占用主内容区 |
| 折叠状态持久化到会话 | 用户一次关闭后不应每次重开；可存 `session.memory` 或 `app.state` |
| 默认快捷键使用 `]` / `[` 或 `ctrl+x r` | `]` 不冲突、`ctrl+x r` 与 OpenCode 社区提案对齐 |
| 斜杠命令使用 `/panel` 或 `/tasks --side` | `/panel` 作为 toggle 最直观 |
| 内容分区模块化 | 便于后续添加 MCP、context 等区块 |
| 复用 `formatTaskList` | 已有成熟实现，避免重复造轮子 |

## Key Questions

1. 面板默认是打开还是关闭？→ 建议默认关闭，宽屏用户可手动打开。
2. 宽度固定 28 还是可选 32/40？→ 建议可配置，默认 32（比当前 28 稍宽，容纳 task 进度条）。
3. 是否支持鼠标点击折叠按钮？→ T9 当前以键盘为主，第一阶段可不做鼠标。
4. 是否需要在 overlay 中也能看到面板？→ 不需要，overlay 全屏覆盖，退出后恢复。
