# Task Plan: 可折叠右侧面板（OpenCode 风格）

## Goal

## Key Questions

1. 面板默认打开还是关闭？→ 默认关闭，用户手动打开。
2. 宽度多少？→ 默认 32。
3. 快捷键？→ `]` toggle，`ctrl+x r` 兼容 OpenCode 习惯。
4. 是否鼠标可点？→ 第一阶段仅键盘。
5. context 文件区？→ 不做。
6. MCP/Skills 区？→ 本次不做。
7. 任务区？→ 展示会话内已完成 + 进行中任务（TodoStore）。
8. "文档任务计划" 是否要在面板展示当前 `task_plan.md`？→ 待用户确认。

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| 可折叠，非常驻 | 用户明确要求，避免侵占主内容区 |
| 折叠状态保存于 `app.state`（本次会话内） | 先满足会话内状态，持久化到 disk 后续再补 |
| section-based 模块化渲染 | 便于后续扩展，当前只保留必要 section |
| 复用 `formatTaskList` | 已有成熟实现，含进度条与三态 |
| 默认宽度 32 | 用户确认 |
| 快捷键 `]` toggle，`ctrl+x r` 兼容 OpenCode | 用户确认先这样 |
| 不做 context 文件区 | 用户认为太复杂 |
| 不做 MCP/Skills 区 | 用户放到后续迭代 |
| 任务区展示会话内已完成 + 进行中任务 | 用户明确要求 |
