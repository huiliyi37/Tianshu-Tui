# 消息流图片预览 实现计划

**目标：** 用户在桌面端发送图片后，消息流中显示缩略图预览而非仅「📷 N 张图片」文字。

**架构：** 图片 base64 data URL 随同 `user` SSE 事件从服务端回传桌面端，ConvoBlock 新增 `images` 字段承载，ThreadView 用户消息块渲染缩略图。服务端仅需在 `RuntimeSessionManager.run()` 的 user 事件中补传 `images` 字段——图片本身已在请求体中，零额外存储开销。

## Tasks

### Task 1 — 服务端 user 事件补传 images
**文件**: `src/server/session-manager.ts:506`
将 `this.append(session, 'user', { text: prompt, ...(images?.length ? { imageCount: images.length } : {}) })` 改为 `this.append(session, 'user', { text: prompt, ...(images?.length ? { imageCount: images.length, images } : {}) })`

新增测试验证 user 事件 `data.images` 字段。

### Task 2 — ConvoBlock 加 images 字段
**文件**: `desktop/src/state/event-reducer.ts`
- ConvoBlock 接口加 `images?: string[]`
- `case 'user'` 消费 `ev.data.images`

### Task 3 — ThreadView 渲染缩略图 + CSS
**文件**: `desktop/src/surfaces/ThreadView.tsx` + `desktop/src/styles.css`
- 用户消息块：`block.images` 优先渲染 `<img>` 缩略图，回退到 `📷 N 张图片` 文字
- CSS: `.msg-thumb` 样式 (max-width:200px, max-height:160px, border-radius, inline-block)
