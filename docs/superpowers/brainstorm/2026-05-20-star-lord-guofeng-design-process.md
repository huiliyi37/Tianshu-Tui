> 核心驱动力：「我们国内东方的星辰要面向世界！」

## 一、设计起点：为什么需要「国风再造」

### 原版问题诊断

原版设计（avatar-styles-design.md）虽然框架扎实，但存在三个美学断层：

| 断层 | 具体表现 | 根因 |
|------|---------|------|
| **命名西化** | "文生态/武生态"、"文生/武生" | 借用布袋戏术语但未升华为星辰叙事 |
| **视觉平庸** | `·★·` 通用星号、`(◠‿◠)` 日式 kaomoji | 缺少中国终端美学的独特辨识度 |
| **色彩无根** | Observatory 色板用 hex 编号命名 | 没有连接到中国传统色彩体系 |

**一句话诊断**：框架很好，但「皮」不够东方。七星是中国的北斗七星，角色是中国的星辰之官，视觉必须是东方的。

## 二、设计跃迁：三大核心变革

### 变革 1：从「文生武生」到「星君」

**思考过程**：

```
布袋戏「文生/武生」
  → 太小众，国际用户不理解
  → 但「文/武」二元对立是对的
  → 需要一个更大的叙事框架…

北斗七星是中国古代天文学的核心
  → 天枢、天璇、天玑、天权、玉衡、开阳、摇光
  → 每颗星都有「星君」——道教星辰人格化的传统
  → 「星君」= 星辰之神 = 天上的官员
  → 文官治世，武官定疆——这是中国政治哲学的根基
```

**设计决策**：

| 角色 | 星君名号 | 五行属性 | 职责隐喻 |
|------|---------|---------|---------|
| 文官 | **天玑星君**（文星） | 水（智） | 观局、谋略、定标——「运筹帷幄」 |
| 武官 | **玉衡星君**（武曲） | 火（勇） | 铸形、试锋、交付——「决胜千里」 |

为什么选「天玑」和「玉衡」？
- 天玑 = 北斗第三星，古代象征「智慧之光」，掌管谋略
- 玉衡 = 北斗第五星，古代象征「权衡之力」，掌管执行
- 两者之间隔着「天权」——正好是决策的转折点

### 变革 2：从 kaomoji 到「星纹印章」

**思考过程**：

```
kaomoji `(◠‿◠)` 是日本终端文化
  → 全球开发者都能读懂 ✓
  → 但没有中国美学辨识度 ✗
  → 需要一个既有东方感、又全球可读的方案…

中国印章（篆刻）
  → 方寸之间，气象万千
  → 一个「文」字或「武」字就是全部信息
  → CJK 字符在等宽字体中天然等宽！
  → 终端渲染零兼容问题！

组合方案：印章冠 + kaomoji 面
  → 头顶是东方印章（`╭文╮` / `╰星╯`）
  → 面部保留 kaomoji（全球通用）
  → 身体是中国礼仪手势（拱手/抱拳）
```

**设计决策**：

```
╭─ 文 ─╮       ← 印章冠：CJK 字符 + 方框
│ ◠‿◠ │        ← 面部：kaomoji（全球通用）
╰──┬──╯
  ╱拱╲         ← 身体：中国礼仪手势
  ╲手╱
```

这解决了「面向世界」的需求：
- 中国用户：看到印章冠就知道是「天枢星君」
- 国际用户：看到 kaomoji 就知道角色在微笑
- 两种文化的交汇点，不是非此即彼

### 变革 3：从 hex 色值到「五色星辰」

**思考过程**：

```
原版色板：primary=#818cf8, secondary=#a78bfa…
  → 技术上正确，但没有灵魂
  → 需要一个有文化根基的色彩体系…

中国传统五色：青、赤、黄、白、黑
  → 对应五行：木、火、土、金、水
  → 对应五方：东、南、中、西、北
  → 北斗七星在北方 → 水 → 玄色（深蓝黑）

但五色太抽象，需要落地为终端色…
  → 靛蓝（文星君主色）= 青出于蓝
  → 朱砂（武曲君主色）= 丹砂之赤
  → 星金（活跃状态）= 中央之黄，星辰之光
  → 月白（辅助色）= 白中带青，月光色
  → 玄墨（边框/分隔）= 北方之黑，深空色
```

**设计决策**：

| 色名 | 五行 | Hex | 用途 | 文化意象 |
|------|------|-----|------|---------|
| 靛蓝 | 木·青 | `#4f46e5` | 文星君主色 | 青出于蓝，智慧之色 |
| 朱砂 | 火·赤 | `#dc2626` | 武曲君主色 | 丹砂之赤，勇武之色 |
| 星金 | 土·黄 | `#f59e0b` | 活跃/高亮 | 星辰之光，中央之色 |
| 月白 | 金·白 | `#e2e8f0` | 文字/辅助 | 月光色，清冷明亮 |
| 玄墨 | 水·黑 | `#1e1b2e` | 深空底色 | 北方之黑，深空色 |
| 远星灰 | — | `#64748b` | 非活跃/次要 | 远处星辰的微光 |

## 三、视觉演化：从概念到帧表

### 第一稿：过度设计（被否决）

```
╭──── 文 ────╮
│   ╭─☆─╮   │      ← 太复杂，印章里套星
│   │文星│   │
│   ╰───╯   │
│   ◠‿◠     │
╰────┬────╯
    ╱拱╲
    ╲手╱
```

问题：6 行太高，信息密度低，印章嵌套不合理。

### 第二稿：过度简约（被否决）

```
文星 (◠‿◠)
 拱手
```

问题：太简陋，没有「星君」的仪式感，跟普通终端提示没区别。

### 第三稿：定稿 ✅

```
╭文╮
│星│         ← 印章冠：2行，带边框
╰┬╯
◠‿◠          ← 面部：1行kaomoji
╱拱╲         ← 身体：1行手势
╲手╱
观局中…       ← 状态：1行
```

**6行，每一行都有独立信息**：
1. 印章上框 + 角色标识
2. 印章下框 + 角色名号
3. 连接线
4. 面部表情（情绪）
5-6. 身体姿态（动作模式）
7. 状态文字（当前行为）

**武曲对照**：

```
╭武╮
│曲│
╰┬╯
●△●
╱⚔╲
╲拳╱
编码中!
```

**对比度极高**：
- `文星` vs `武曲` → 身份一目了然
- `◠‿◠` vs `●△●` → 情绪完全不同
- `拱手` vs `抱拳` → 动作模式切换
- `靛蓝` vs `朱砂` → 色彩截然对立

## 四、表情系统设计：12 种状态

### 设计原则

1. **萌三角**：眼+嘴构成倒三角，3 个字符传达情绪（来自 Chibi 设计研究）
2. **模式优先**：文/武切换比微表情变化显眼 100 倍（来自布袋戏洞察）
3. **永不静止**：呼吸节奏 + 星辰闪烁 = 灵魂底线（来自木偶戏共识）

### 完整表情表

| 情绪 | 表情 | 文/武 | 触发条件 | 文化意象 |
|------|------|-------|---------|---------|
| 平静 | `◠‿◠` | 文 | 观局/idle | 「静如处子」—— 文星君的常态 |
| 搜索 | `◉_◉` | 文 | 寻迹/定位 | 「眼观六路」—— 四处搜寻 |
| 专注 | `◡▽◡` | 文 | 拆解/立约 | 「运筹帷幄」—— 胸有成竹 |
| 满足 | `◡▿◡` | 文 | 归航/完成 | 「功成身退」—— 事毕收工 |
| 从容 | `◠ω◠` | 文 | 再临/重启 | 「处变不惊」—— 二次请星 |
| 骁勇 | `●△●` | 武 | 铸形/编码 | 「横刀立马」—— 武曲君出阵 |
| 锐利 | `◎─◎` | 武 | 试锋/测试 | 「目不转睛」—— 锁定目标 |
| 困惑 | `×~×` | 文 | 卡住/未知 | 「百思不解」—— 遇到难题 |
| 震惊 | `○△○` | 武 | 错误/失败 | 「大惊失色」—— 测试挂了 |
| 警觉 | `◎△◎` | 武 | 高风险 | 「如临大敌」—— 风险评估 |
| 重逢 | `●─●` | 文 | encore | 「故人重逢」—— 旧路再访 |
| 开启 | `◠▽◠` | 文 | 首次/开场 | 「初出茅庐」—— 天枢就位 |

## 五、星辰冠设计：8 种相位

### 设计原则

1. **印章框架**：`╭X╮` / `╰X╯` 保持不变，只变中间字符
2. **CJK 优先**：用中文字符（文/武/天/星）而非 Unicode 符号
3. **光效暗示**：用数量和符号暗示光亮度

### 星辰冠表

| 相位 | 星冠 | 视觉 | 含义 |
|------|------|------|------|
| 观局 | `╭文╮` | 文星印章 | 文官临朝 |
| 寻迹 | `╭文╮` | 同上（搜索是面部变化） | — |
| 拆解 | `╭文╮` | 同上 | — |
| 立约 | `╭文╮📜` | 印章 + 卷轴 | 签约时刻 |
| 铸形 | `╭武╮` | 武曲印章 | 武官出阵 |
| 试锋 | `╭武╮` | 同上（锐利是面部变化） | — |
| 归航 | `╭✦╮` | 纯星芒 | 凯旋之光 |
| 再临 | `╭天╮` | 天枢印章 | 天枢本尊 |

**设计洞察**：印章冠的切换次数很少（文/武/天枢/星芒 4 种），面部才是高频变化。这符合「模式切换 > 微表情」的核心原则。

## 七、「面向世界」设计哲学

### 核心原则

> 东方美学不是封闭的审美部落，而是开放的文化语言。

### 三层可读性设计

| 层次 | 内容 | 受众 | 可读性 |
|------|------|------|--------|
| **表层** | kaomoji 面部 `(◠‿◠)` | 全球开发者 | 零学习成本 |
| **中层** | 印章冠 `╭文╮` + 五行色彩 | 东亚文化圈 | 直觉感知 |
| **深层** | 星君叙事 + 天玑/玉衡典故 | 中国文化爱好者 | 文化共鸣 |

**关键决策**：三层之间不是「降级」关系，而是「叠加」关系。
- 国际用户看到 kaomoji，就知道角色在微笑（表层）
- 中国用户看到印章冠，就知道是文星君（中层）
- 文化爱好者看到天玑/玉衡，会心一笑（深层）

**每一层都完整，叠加更丰富。**

### 对标国际产品

| 产品 | 角色系统 | 文化策略 | 我们的对标 |
|------|---------|---------|-----------|
| Claude Code | `/buddy` 3帧 ASCII | 纯西方极简 | 我们更丰富，但同样极简 |
| GitHub Copilot | 星点动画 | 无文化属性 | 我们有文化叙事，更有辨识度 |
| Warp Terminal | AI 助手图标 | 扁平化设计 | 我们用字符艺术，终端原生 |
| Cursor | 无角色系统 | 纯功能 | 我们有情感连接 |

**我们的独特定位**：全球唯一一个用中国传统星辰美学的终端 AI 角色系统。

## 八、技术决策记录

### 决策 1：保留 kaomoji 而非纯 CJK 面部

**选项**：
- A. 纯 CJK 面部：`文星` 代替 `(◠‿◻)`
- B. 保留 kaomoji + CJK 印章冠（选择 ✅）
- C. 纯 ASCII 面部

**理由**：kaomoji 是全球终端文化的通用语言，零学习成本。CJK 印章冠提供东方辨识度。两者叠加 = 面向世界。

### 决策 2：星君名号用 2 字而非 3 字

**选项**：
- A. `天玑星君`（4字）→ 太长
- B. `文星` / `武曲`（2字）（选择 ✅）
- C. `文` / `武`（1字）→ 信息不足

**理由**：2 字在印章框内刚好，视觉平衡。`文星` 暗示文官之星，`武曲` 暗示武曲星，都有星象典故。

### 决策 3：五行色用现代色名而非古色名

**选项**：
- A. 古色名：「靛蓝」「朱砂」「月白」
- B. 现代色名 + 古色名注释（选择 ✅）
- C. 纯 hex 编号

**理由**：代码中用 `indigo`/`cinnabar`/`moonwhite` 便于开发者理解，注释中保留古色名作为文化参照。

### 决策 4：炼金阶段用五行重新诠释

**原版**：nigredo/albedo/citrinitas/rubedo（西方炼金术）
**新版**：保留英文类型名，但视觉映射到五行色

理由：不改类型名保持 API 兼容，但视觉上用五行色替代无意义的灰/白/黄/红。
