# 星桥四站位 — 下一代终端 Agent 可观测性设计

> 日期：2026-05-20
> 来源：deep-brainstorm 三轮达尔文演化（3 技术 scout + 1 反证 scout）
> 前置：天枢之眼 v1 已实现（星相 strip + 天枢无线电 hook）
> 核心洞察：信息应该分层呈现，不同层用不同的注意力通道——而非堆更多文字

---

## 问题

天枢之眼 v1 解决了 "agent 执行时用户看不到状态" 的问题，但引入了新问题：radio 消息在对话流中刷屏太快，来不及读就消失了。右侧面板是人类的第一反应，但它只是 IDE 的惯例——不是唯一解。

**反证 scout 的关键质疑：**
- 视觉外周注意力和聚焦阅读争夺同一资源，没有稳定中间态
- 面板会像 banner 一样被习惯化忽略
- 终端屏幕是平面发光体，没有物理空间的深度和视差

---

## 核心架构：五层注意力金字塔

```
Layer 0 — 氛围（色温 + 声音）     ← 不需要看终端就知道状态
Layer 1 — 心跳（底部 strip）       ← 扫一眼就知道阶段和进度（已有）
Layer 2 — 全景（星图全屏）         ← 按需进入，2 秒理解全局
Layer 3 — 叙事（传说视图）         ← 历史和上下文
Layer 4 — 诊断（cockpit）         ← 深度分析（已有）
```

灯塔守望者类比：灯塔有光（Layer 0）、有笛声（Layer 0）、有望远镜（Layer 2）、有日志簿（Layer 3）。守望者在不同需求强度下使用不同层。

## 氛围增强层（可选，Phase 4）

在支持 24bit 色的终端中：

| Agent 状态 | 色温 | 效果 |
|-----------|------|------|
| 探索期（低 confidence） | 冷蓝 #8BB4D9 文字 | 安静、探索的氛围 |
| 执行期（高 confidence） | 暖黄 #D4A574 文字 | 积极、推进的氛围 |
| 测试期 | 高对比度 白/黑 | 紧张、验证的氛围 |
| 异常/stuck | 暗红 #2E1A1A 背景 + BEL | 告警 |
| 正常恢复 | 2 秒渐变回默认 | 放松 |

不支持 24bit 色的终端自动跳过。

## 预期效果

### 信息获取对比

| 需求 | v0（当前） | v1（天枢之眼） | v2（星桥） |
|------|-----------|---------------|-----------|
| "在哪个阶段" | 不知道 | 看 strip（1s） | 看 strip 或按 2 看星图（1s） |
| "做到哪里了" | 不知道 | 看 strip 步骤（1s） | 看 strip 或按 3 看传说（2s） |
| "在干什么" | 读英文 thinking | 看 [天枢] 消息（但会刷走） | 按 2 看星图 radio 区（2s，不刷走） |
| "是否正常" | 不知道 | 看色带 | 色带 + 异常时 BEL 声音（0s） |
| "做了什么" | 翻聊天记录 | 翻聊天记录 | 按 3 看传说（结构化历史） |
| "详细诊断" | Ctrl+K cockpit | Ctrl+K cockpit | 按 4 驾驶舱（同 cockpit） |

### 关键改进

1. **Radio 消息不再刷走** — 固定在星图模式中，最近 5 条始终可见
2. **执行历史有结构** — 传说视图把 30 个 tool calls 浓缩为 3-5 个 phase 段落
3. **不增加默认复杂度** — 模式 1（默认）和现在完全一样，只有主动按键才进入新视图
4. **有 Rivet 灵魂** — 打开星图看到紫微七星，这是 "智能体与星辰" 的具象化

## 风险评估

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| Ink 6 全屏模式切换闪烁 | 中 | 低 | useRef 缓存上一帧 + 过渡动画 |
| Unicode 星座图对齐困难 | 中 | 中 | 用 box-drawing 不用 emoji；测试 3 个主流终端 |
| 用户不知道可以按 2/3/4 | 高 | 中 | 在 strip 末尾显示 `[2:星图 3:传说]` 提示 |
| 传说视图数据不够丰富 | 低 | 低 | Phase 1 先用 radio 事件，后续可加 tool history |
| 色温在某些终端不工作 | 中 | 低 | Graceful degradation，自动检测 |

## 三轮演化摘要

**第一轮（变异）：** V1 观星台面板 / V2 星桥站位切换 / V3 星脉氛围引擎 / V4 星辰编年史

**第二轮（选择）：**
- V4 灭绝：实时监控需求断裂（agent 卡住时用户盲等）
- V1 降级：功能正确但无超越性（IDE 面板套路）
- V3 降级：终端兼容性风险
- V2 存活：按需深入 + 全屏星图（Rivet 灵魂）

**第三轮（适应）：**
- V4 trait 回收：编年史叙事 → 传说模式内容源
- V1 trait 回收：面板布局 → 星图模式内部使用
- V3 trait 回收：氛围色温 → 可选增强层
- 收敛洞察：信息分层呈现，不同层用不同注意力通道
