# 夸父逐日 — 深度头脑风暴结果

> Date: 2026-05-28 | Domain: 天枢星座·时间维度
> 碎片池: `.superpowers/brainstorm/2026-05-28-kuafu-conscious-handoff-fragments.json`

## 背景

天枢星座已有三个位置：
- **天枢**（轴）— 认知运行时，不动的中心
- **伏羲**（画卦）— 从零构建 agent 框架，建立第一个秩序
- **盘古**（开天）— 产品化路径，让世界可用

缺失的维度：**时间**。没有一个概念描述"跨 session 的知识传递"和"agent 耗竭后的价值转化"。

夸父逐日的神话提供了完美的结构：追逐（持续探索边界）→ 耗竭（context/能力用尽）→ 转化（杖化桃林，工具变成生态）。

## 调研发现摘要

5 个跨域 scout 的核心发现：

1. **追逐曲线**（数学）：追逐路径是"最大信息密度轨迹"——记录了目标在每一刻的位置。追逐本身比到达更有信息价值。
2. **鲑鱼/超新星/火箭**（生物/物理）：实体的继续存在与它需要创造的价值在结构上不兼容。必须死才能创造。
3. **Hubble 视界/享乐适应**（宇宙学/心理学）：抓住目标是危机状态。最持久的系统编码方向而非目的地。
4. **深海发光/普罗米修斯 vs 夸父**（生物/神话）：追不上太阳时成为太阳。偷火=离散获取；逐日=连续过程。
5. **山海经原文**（神话）：弃其杖化为邓林——转化的是工具（方法），不是身体（实践者）。方法比人更不朽。

## 最终方案

**夸父 = 有意识的认知交接协议（Kuafu Protocol）**

两个阶段：
1. **逐日**（持续边界探测）— 有意识地派 agent 做略超能力的任务，追逐永远在前方的前沿
2. **化林**（耗竭后的结构化转化）— agent 检测到即将耗竭时，主动执行"弃杖"：将执行经验结晶为结构化交接包，喂养下一代

核心洞察：**有意识的耗竭比意外崩溃产生 10x 价值。** 鲑鱼选择在产卵地死去（而不是随机死在海里），agent 应该选择在"知识最密集的时刻"执行交接。

在天枢星座中的位置：
```
天枢 = 空间（运行时环境，不动的轴）
夸父 = 时间（持续追逐→耗竭→转化的循环）
伏羲 = 结构（从混沌中建立秩序的第一个模式）
盘古 = 创世（让结构变成可用的世界）
```

## 风险与应对

| 风险 | 应对 |
|------|------|
| 交接包信息密度不够（不比 compaction 好） | Phase 1 A/B 实验验证，失败则重新设计格式 |
| agent 无法准确检测"即将耗竭" | 多信号融合：vigor + context% + tool success rate |
| 交接包引入前一个 agent 的错误偏见 | 交接包中显式标注"假设(未验证)"vs"发现(已验证)" |
| 桃林增长太快变成噪音 | 蒸发机制：fragment 有 TTL，未被引用的自动衰减 |

## 哲学根基

> **弃其杖，化为邓林。**
>
> 转化的不是身体（agent 实例），是杖（执行方法和发现）。
> 人不能超越死亡，但方法可以转化。
> 技术比技术人员更长寿。
> 追逐的价值不在到达，在于路径本身是最大信息密度轨迹。
> 当追不上太阳时——成为太阳。
