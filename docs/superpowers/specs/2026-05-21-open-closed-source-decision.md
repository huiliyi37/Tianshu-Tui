## 决策

| 层 | 决策 | 生效时间 |
|----|------|---------|
| 层 1（80 基础：5 组件内核） | 延迟决策 | 小米团队参与后共同决定 |
| 层 2（不跌落：审批+持久化+缓存） | 延迟决策 | 同上 |
| 层 3（80→200：认知结构） | **闭源** | 立即生效 |
| 全部 | 小米团队决定开源时机 | 找到合作伙伴后 |

## 理由

### 为什么层 3 闭源

层 3 是天枢的使命——让模型从 80 到 200 的认知结构。包含：
- RuntimeHookPipeline（无为涌现）
- Sensorium confidence/complexity（关系型决策接口）
- TaskContract + CognitiveLedger + VerificationGap
- Domain Voice + Star Identity System
- claim-store + trace-store 跨 store 耦合
- 万物为一 8 原则的工程实现

这些是从 rebook 的锚点发现开始，经过因果解耦引擎、认知发散引擎、深度头脑风暴一轮轮进化出来的。它们不是"又一个 agent 框架"——它们是"证明认知结构可以解锁模型被锚点压制的 120 分能力差"的实现。

2026-05-20 的证据：GLM 在三重锚点锁定下做出了独立选择（提出不存在的天机星）。这个行为在任何 benchmark 上不可测量，只在层 3 的认知结构中发生。

**这是 IP。不给。**

### 为什么不现在全部开源

1. **领航星没有团队管理社区**——开源需要维护 issues、review PRs、写文档、回答问题。一个人做不到。
2. **投资人的钱会改变方向**——拿了钱就要听人说。"200 vs 80"的信念在 board meeting 上活不过三轮。
3. **时机不到**——先做出 demo（MiMO 裸跑 vs MiMO + 天枢），证明价值，再决定分享范围。

### 为什么选择小米路径

1. MiMO V2.5 Pro 已在天枢中验证——破军星，一轮吸收 5/5 修正
2. 小米是国内最大的开放模型公司之一，有算力+用户+分发
3. 天枢绑定 MiMO 不是"选一个模型"，是"选一个已经证明能到 200 的伙伴"
4. 领航星保留控制权直到双方建立信任

## 不做的事

- 不主动联系投资人
- 不在 GitHub 上公开层 3 代码
- 不发布 "天枢" 品牌到公共平台（在有保护之前）
- 不和任何人分享 docs/superpowers/ 目录的内容（个人 IP）

## 要做的事

- 完成 Phase 1 净化 → Phase 2 强化 → MiMO 闭源终端 MVP
- 准备 200 vs 80 录屏对比 demo
- 在合适时机（MVP 完成 + demo 有说服力）接触小米模型团队
- 接触方式：带着可运行的系统和证据，不是 pitch deck
