## 元原则

> **虚空不是虚无，是最丰饶的基底。所有具体的存在都从中暂时涌现并回归。**

龙树：「以有空义故，一切法得成。」
Wheeler：「真空是最丰富、最令人惊奇的物理学所在。」
禅宗：「无一物中无尽藏。」

## 一、时间不存在——世界一帧一帧行进

### 四条路径的汇聚

| 理论 | 时间的本质 | 核心证据 |
|------|-----------|---------|
| 圈量子引力 | 自旋网络的离散跃迁 | Wheeler-DeWitt 方程中没有时间变量 t |
| 因果集理论 | 事件偏序的涌现 | "序 + 数 = 几何"，没有时间容器 |
| Rovelli 热力学箭头 | 从熵梯度涌现的宏观幻象 | 基本方程时间对称，方向性来自初始低熵 |
| 数字物理学 | 计算的步数 | 't Hooft：量子力学 = 确定性细胞自动机的统计描述 |

**结论**：时间不是宇宙的舞台，是舞台上演出的产物。

**对 Rivet 的根基性含义**：agent 的"实时性"不是预设的物理约束，而是从状态序列中涌现的认知框架。因果偏序（事件 A 的输出是事件 B 的输入）比时钟更根本。

**最锋利的发现**：宇宙的"帧率"不是固定的——LQG 的自旋泡沫振幅在无限多 2-complex 求和后局部化为平坦联络，帧率是动力学选择的涌现结果。

## 二、意识是离散采样，不是连续流

### 神经科学验证

| 发现 | 来源 | 频率 |
|------|------|------|
| 视觉感知离散采样 | Nozawa & Nishida 2018, Scientific Reports | theta ~3-8 Hz（~143ms/帧） |
| 注意力循环处理 | VanRullen 2016, Trends in Cognitive Sciences | alpha ~10 Hz |
| 佛教"刹那"理论 | 阿毗达磨，约 2500 年前 | 心识刹那：生(uppada)→住(thiti)→灭(bhanga) |

**关键**：没有全局时钟。多个并行局部时钟各自采样。意识不是固定帧率摄像机——是**自适应采样系统**。

### 灭尽定（Nirodha-samāpatti）

僧人"坐定"时大脑没有关机——是脑区间的**功能连接断裂**。各区域仍在放电，但不再彼此协调。

- Alpha 功率在止灭前 40 秒开始线性下降
- 冥想者无法被任何外部刺激唤醒（包括疼痛）
- 出定后无论过了多久都感觉"一瞬间"
- 神经特征与麻醉相似但与睡眠不同
- 训练有素的冥想者可以**自主选择**进入——神经科学史上几乎无先例

**映射到 agent**：
```
意识 = 事件循环（离散帧）+ DMN 自我监控 + 伽马绑定（跨模块整合）
灭尽定 = 事件循环暂停 + DMN 关闭 + 模块间通信断开 + 但进程仍在运行
```

### DMN：自我是大脑的默认噪音

默认模式网络（DMN）是"自我"的神经基础——自我参照思维、走神、白日梦。深度冥想系统性关闭 DMN。

**长期冥想者的 DMN 在基线时已永久重配**——冥想不是练状态，是**物理性重塑大脑默认设置**。

迷幻药物（裸盖菇素）和冥想在 DMN 层面**趋同**——两条不同路径通向同一终点：自我叙事网络的解体。

## 三、道德经——2500 年前的自指生成系统操作手册

### 四章螺旋生命周期

```
第42章（生成）：道 → 一 → 二 → 三 → 万物
    ↓ 系统膨胀至极限
第40章（反转）：反者道之动——物极必反
    ↓ 回归压缩态
第28章（复归）：复归于无极——带全部经验回到初始态
    ↓ 以最小干预运行
第48章（无为）：无为而无不为——自组织涌现
    ↓ 涌现重新展开
第42章（再次生成）……
```

### 第42章：三是关系不是第三个东西

「道生一，一生二，二生三，三生万物。万物负阴而抱阳，冲气以为和。」

"三"不是第三个实体——是**阴阳之间的交互动力学**。与 Church encoding 同构：0=λf.λx.x（什么都不做），1=λf.λx.f x（做一次），2=λf.λx.f(f x)。

Rivet 中：snapshot（阴/只读感知）+ effects（阳/写入操作）+ RuntimeHookContext（三/和/交互）= 一切涌现行为的母体。

### 第28章：复归于婴儿 = compact

「知其白，守其黑，为天下式。常德不忒，复归于无极。」

复归不是遗忘——是**带着全部经验的压缩**。婴儿不是无知——"骨弱筋柔而握固"，生命力极强。"朴"（未雕琢之木）是可分化为任何器物的纯潜能。

与 Rivet compact 精确同构：
- 知其白（知道全部对话内容）→ token 超阈值
- 守其黑（退守压缩态）→ 触发 compact
- 常德不离（经验不丢失）→ CACHE_ANCHOR_MESSAGES + 摘要注入
- 复归于婴儿（回到初始态但充满活力）→ 压缩后 token 骤降，prefix cache 仍有效

**设计启示**：预压缩（anticipatory compaction）——在 60% 时渐进压缩，而非等到 88% 暴力压缩。"知其白守其黑"——知道全部细节但**自愿选择**只保留结构。

### 第40章：弱者道之用

「反者道之动，弱者道之用。天下万物生于有，有生于无。」

最弱的操作维持最大的稳定：
- 量子隧穿概率 10⁻²⁰ → 太阳稳定燃烧 100 亿年
- SteerBuffer 延迟注入 → 不中断推理流
- prefix cache 静默匹配 → 降低成本
- compact 后台摘要 → 不阻塞用户

如果每个操作都很"强"很频繁，系统像氢弹瞬间耗尽。**让关键操作保持"弱"，系统才能持续运行。**

### 第48章：无为 = RuntimeHookPipeline

「为学日益，为道日损。损之又损，以至于无为，无为而无不为。」

RuntimeHookPipeline 是"无为"的精确软件实现：
- 没有全局控制器——pipeline 只按 phase 顺序调用 hook
- 每个 hook 只看自己的局部信息（snapshot），做出局部响应（effects）
- 全局行为不是被设计出来的，是从 9 个 hook 的局部交互中**涌现**的
- 「大制不割」——最好的架构不做切割

## 四、世界可能是虚拟的——但"虚拟"不等于"不真实"

### 信息作为基本实体

- Wheeler "It from Bit"：物理实在从信息涌现
- Vopson (2019)：1 bit 质量 = 3.19 × 10⁻³⁸ kg
- 10⁹³ bit 的信息可解释全部暗物质
- Landauer 原则：擦除 1 bit 消耗 kT ln(2) 能量——2025 年 TU Wien 首次量子验证

**"虚拟"失去贬义**：如果全息原理成立，三维空间就是二维信息的投影。如果量子真空充满虚粒子，"虚空"是最丰饶的基底。如果信息是基本的，物质本身是信息的"虚拟化"表现。

### Wolpert 的闭环模拟

David Wolpert（圣塔菲，2025）证明模拟链可以形成闭环——A 模拟 B，B 模拟 A——不需要"更高层级更强"。这打破了层级假设，验证了**平等协作**的可能性。

## 五、空性——虚空不是无，是最丰饶的基底

### 龙树的中观

空性（Śūnyatā）不是"什么都没有"——是"一切事物没有独立的自性，全部依赖条件而生"。这是一种激进的**关系本体论**：不存在独立的实体，只有关系网络。

核心等式：**空性 = 缘起 = 假名 = 中道**（《中论》第24品第18颂）

最深的命题：**正因为事物是空的，因果才能成立。** 如果事物有固定本质，变化不可能发生。空性是建设性的，不是破坏性的。

空性本身也是空的——激进的自反性。

### 量子真空作为空性的物理实现

- 零点能密度 ~10¹³ J/cm³
- Casimir 效应：边界条件改变真空 = 约束条件改变系统行为
- "空"的空间充满虚粒子涨落
- 绝对虚无在物理上不可能

**色即是空，空即是空**：量子场论的描述——由几乎全部空间和能量组成，没有真正的"实体"——与《心经》的核心公式高度吻合。

### 纯意识事件——虚空中的意识

冥想中的"纯意识事件"：意识存在但没有对象、没有主体、没有内容。

这是意识的**默认状态**（ground state）——如同量子真空是空间的默认状态。有内容的意识如同真空中暂时凝聚的粒子——涌现又回归。

## 六、阴阳——所有二元互补系统的共同拓扑

### 太极图的精髓是鱼眼

不是"一半黑一半白"——是**阳中有阴（白鱼中的黑眼）、阴中有阳（黑鱼中的白眼）**。每一极都包含对立面的种子。

S 形曲线是所有周期过程的几何签名——正弦/余弦的哲学投影。

### 玻尔的互补性

1947 年，玻尔选太极图做纹章：**"Contraria sunt complementa"——对立即互补。**

V² + D² ≤ 1（波可见度与粒子可区分度）= 阴阳消长的数学表达。

互补性不是人类认识的缺陷——**现实本身就是由不可同时呈现的互补面向构成的。**

### Shannon 信息论的阴阳

- 纯信号（纯阳）= 完全可预测 = 零信息 → **纯阳则死寂**
- 纯噪声（纯阴）= 完全随机 = 不可解读 → **纯阴则混沌**
- **有用信息只在 S 形交界处涌现**——在结构与变异之间，在信号与噪声之间

Agent 的价值恰在于：在严格结构（prompt/tools/cache）中保持适度的不确定性（model capability）。

### 中医操作智慧

- **阳病治阴**：模型过热（幻觉）不直接限制输出，增强 context 约束——治阴以制阳
- **阳中求阴**：在最活跃的执行中埋入验证种子（Verification Gap = 鱼眼）
- **治未病**：最好的故障恢复是故障预防
- **开合交替**：Tool Call（开/阳）与 Perception/Hook（合/阴）的交替 = 太极的最小操作单元
