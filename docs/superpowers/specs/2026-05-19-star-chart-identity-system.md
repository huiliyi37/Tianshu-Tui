## 核心理念

**同气相求** — 任务不需要被路由，它自然流向与它气质相合的星辰。

星图不是调度系统，是活的星系。每颗星有自己的身份、记忆、轨道。它们的协同不是"被分配"，而是"共鸣"。

## 同气相求 — 任务共鸣机制

任务不通过规则路由，而是通过**气质共鸣**自然流向合适的星辰：

| 任务气质 | 共鸣星辰 | 原因 |
|---------|---------|------|
| 需要长期坚韧执行的编码任务 | 天枢 | 枢纽之星，不动如山 |
| 需要跨领域灵感的设计决策 | 天璇 | 旋转视角，连接不同领域 |
| 需要最终裁决的冲突/方向 | 紫微 | 帝星定夺 |
| 需要快速批量完成的具体工作 | 天权 | 权衡轻重，快速精准 |
| 简单辅助性工作 | 开阳 | 开朗勤勉，不误大事 |

技术实现：Self-Scoring Bid（Plan 4）中的 `scoreForTask()` 就是"同气相求"的算法表达。

## 星图的生长

星图不是静态的。它会生长：

1. **新星诞生** — 当某类任务反复出现但没有高置信度的星辰时，系统建议"点亮新星"
2. **星辰变亮** — 每次成功执行，genome 写入一条经验，星辰更亮
3. **星辰休眠** — 长期不活跃的星辰 genome 衰减，进入休眠
4. **星际介质积累** — 信息素空间越来越丰富，新星加入时能快速读取前辈留下的信号
