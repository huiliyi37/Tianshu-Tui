## 任务 1：Tool Output 三层表示

**目标：** 大工具输出不污染 TUI、不浪费模型上下文、仍可追溯完整内容。

**三层结构：**

```
Layer 1 — Raw (完整)
  写入 .rivet/outputs/{toolUseId}.log
  用户需要时可展开查看
  
Layer 2 — Model (压缩)
  注入 LLM 上下文的版本：
  - command / tool name
  - exit code
  - 耗时
  - 前 N 行 + 后 N 行
  - 截断标记 + raw 文件路径
  - 关键错误行（stderr 中含 error/fail/exception 的行）

Layer 3 — UI (摘要)
  TUI 显示的版本：
  - 状态图标（✅/❌）
  - 最后 N 行（默认 5 行）
  - 行数/大小摘要
  - "[Expand] to see full output" 提示
```

## 任务 2：Related Tests 推断

**目标：** 模型改 `src/foo.ts` 后，能自动找到并建议运行 `src/__tests__/foo.test.ts`。

**实现：**
```typescript
// src/tools/related-tests.ts
function findRelatedTests(filePath: string, cwd: string): string[] {
  const candidates = [
    // 同目录 __tests__/
    path.join(dir, '__tests__', base + '.test.ts'),
    // 同目录 .test.ts
    path.join(dir, base + '.test.ts'),
    // 同目录 .spec.ts
    path.join(dir, base + '.spec.ts'),
    // src/ → tests/ 映射
    path.join('tests', relPath.replace('src/', '')),
  ]
  return candidates.filter(f => existsSync(f))
}
```

## 任务 4：Evidence Badge

**目标：** agent 完成时自动追加证据摘要。

**实现：** 在 `AgentLoop.run()` 结束时，根据 session 状态生成 evidence block：

```typescript
function buildEvidenceBadge(session: SessionContext): string {
  return [
    '---',
    `Files read: ${readCount}`,
    `Files modified: ${modifiedCount}`,
    `Tests run: ${testResult}`,
    `Unverified: ${unverified.join(', ')}`,
    `Risks: ${risks.join(', ')}`,
  ].join('\n')
}
```

**数据结构：** 在 `SessionContext` 中新增追踪字段：
