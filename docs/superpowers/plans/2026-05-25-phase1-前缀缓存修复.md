# Phase 1：修复前缀缓存字节泄漏

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development 或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 消除 frozen volatile 前缀中的人为字节泄漏，将命中率从 90% 提升到 93-95%。

**架构：** 三个独立修复 — consolidatedBlock 迁移到 dynamic appendix（消除 habituation promotion 锯齿）、prune 改为请求时 mask（消除存储变异）、工具结果归一化（消除非确定性）。

**关联设计文档：** `docs/superpowers/specs/2026-05-25-deepseek-cache-hit-rate-optimization-design.md`

### 任务 1.1a：consolidatedBlock 迁移 — 失败测试

**文件：** `src/prompt/__tests__/engine.test.ts`

**操作：** 在文件末尾追加新测试，验证 habituation promotion 后 `volatileBlock` 不变且 consolidatedBlock 出现在 dynamic appendix。

**测试代码：**
```typescript
it('P1.1a: volatileBlock unchanged after habituation promotion', () => {
  const engine = new PromptEngine({
    model: 'test',
    maxTokens: 8000,
    staticCtx: { systemPrompt: 'You are a test agent.', tools: [] },
    volatileCtx: { cwd: '/tmp' },
    habituationThreshold: 2, // promote after 2 stable turns
  })

  const baseVolatile = (engine as any).volatileBlock as string
  const frozenBase = (engine as any).frozenBase as string
  assert.equal(baseVolatile, frozenBase, 'volatileBlock should equal frozenBase at startup')

  // Simulate activeDomain becoming habituated over 3 turns
  const messages = [{ role: 'user', content: 'hello' }]
  for (let i = 0; i < 3; i++) {
    engine.setActiveDomain({ name: 'test', volatileBlock: 'block', motto: 'motto' })
    engine.buildOaiRequest(messages)
  }

  // volatileBlock MUST NOT change after habituation promotion
  const afterVolatile = (engine as any).volatileBlock as string
  assert.equal(afterVolatile, frozenBase,
    'volatileBlock should remain at frozenBase after habituation promotion')
})

it('P1.1b: consolidatedBlock injected into dynamic appendix, not frozen prefix', () => {
  const engine = new PromptEngine({
    model: 'test',
    maxTokens: 8000,
    staticCtx: { systemPrompt: 'SYS', tools: [] },
    volatileCtx: { cwd: '/tmp' },
    habituationThreshold: 1, // promote immediately
  })

  // Turn 1: set domain → should appear in dynamic appendix
  engine.setActiveDomain({ name: 'orion', volatileBlock: 'star-data', motto: 'guide' })
  const req1 = engine.buildOaiRequest([{ role: 'user', content: 'turn1' }])

  // Turn 2: same domain → tracker promotes, domain moves to consolidatedBlock
  const req2 = engine.buildOaiRequest([{ role: 'user', content: 'turn2' }])

  // consolidatedBlock (with habituated star-domain) should be in the LAST user message
  const lastUser2 = req2.messages.filter(m => m.role === 'user')
  const lastContent = lastUser2[lastUser2.length - 1]?.content ?? ''

  // Star domain should appear in the content (either in dynamic appendix or consolidated)
  assert.ok(lastContent.includes('star-data'),
    'Habituated domain content should appear in dynamic appendix user message')

  // frozenBase should NOT contain the habituated domain
  const frozenBase = (engine as any).frozenBase as string
  assert.ok(!frozenBase.includes('star-data'),
    'Frozen base should NOT contain habituated content')
})
```

### 任务 1.1b：实现 consolidatedBlock 迁移

**文件：** `src/prompt/engine.ts`

**修改 1：** `buildOaiRequest()` 中 line 147-151 — 停止变异 volatileBlock

```typescript
// 旧代码：
const newConsolidated = buildConsolidatedBlock(renderedHabituated)
if (newConsolidated !== this.consolidatedBlock) {
  this.consolidatedBlock = newConsolidated
  this.volatileBlock = newConsolidated
    ? this.frozenBase + '\n' + newConsolidated
    : this.frozenBase
}

// 新代码：
const newConsolidated = buildConsolidatedBlock(renderedHabituated)
if (newConsolidated !== this.consolidatedBlock) {
  this.consolidatedBlock = newConsolidated
  // volatileBlock stays at frozenBase — consolidatedBlock goes
  // into dynamic appendix (injected after message history, cache-safe).
  // Mutating volatileBlock here would break the exact-prefix cache for
  // ALL subsequent turns.
}
```

```typescript
const fullAppendix = [projection, this.consolidatedBlock, activeAppendix].filter(Boolean).join('\n')
```

### 任务 1.2b：实现 prune 请求时 mask

**文件：** `src/agent/compaction-controller.ts`

**修改：** `maybeCompact()` 中 line 52-57 — 移除 `replaceMessages` 调用

```typescript
// 旧代码：
const pruneResult = pruneStaleToolResults(messages, { contextWindow: this.deps.contextWindow })
if (pruneResult.prunedCount > 0) {
  this.deps.session.replaceMessages(pruneResult.messages)
  const afterPruneTokens = this.deps.session.getEstimatedTokens()
  console.warn(`[prune] pruned=${pruneResult.prunedCount} ...`)
}

// 新代码：
const pruneResult = pruneStaleToolResults(messages, { contextWindow: this.deps.contextWindow })
if (pruneResult.prunedCount > 0) {
  // Prune is now a request-time mask applied in buildOaiRequest (PromptEngine).
  // We compute the would-prune stats here for logging but do NOT mutate storage.
  // This preserves exact-prefix cache: unmodified history = stable byte prefix.
  const afterPruneTokens = this.deps.session.getEstimatedTokens()
  console.warn(`[prune] (request-time mask) would-prune=${pruneResult.prunedCount} freedChars=${pruneResult.freedChars} ctxWindow=${this.deps.contextWindow} tokens=${beforePruneTokens}->${afterPruneTokens}`)
}
```
