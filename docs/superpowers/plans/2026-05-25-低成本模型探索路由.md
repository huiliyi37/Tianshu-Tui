# 低成本模型探索路由 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将 `code_search` / `doc_research` / `plan` 三种探索型 worker 从当前默认的 `mimo` 路由切换到 `cheap` 路由（DeepSeek Flash，零成本），同时把 MiniMax 加入 cheap 后备选项，并设定探索操作的显式 scope 边界防止 token 失控。

**架构：** 修改 `src/config/default.ts` 的 `workers.routing` 把 `repo_summarization` 从 `mimo` 改为 `cheap`，在 `workers.profiles` 中增加 `cheap-minimax` 后备，在 `src/agent/work-order.ts` 的 `WorkOrderScope` 中增加探索预算字段，在 `src/agent/coordinator.ts` 中接入预算检查。

**技术栈：** TypeScript strict、node:test + node:assert/strict、现有 `DelegationCoordinator` + `WorkOrder` 体系。

---

## 1. Scope check

### 1.1 本计划范围

本计划只改三件事：

1. **默认路由切换**：`repo_summarization` 从 `mimo` → `cheap`（DeepSeek Flash）。
2. **MiniMax 后备**：在 `cheap` 之外增加 `cheap-minimax` profile，供无 DeepSeek API key 的部署环境使用。
3. **探索 scope 预算**：在 `WorkOrderScope` 中增加 `maxFiles` / `maxTokens` 可选项，Coordinator 在探索型 worker 启动前校验。

### 1.2 不在本计划范围

- 不修改 `recommendModelForTask` 的评分算法。
- 不添加自适应模型切换（已有 LinUCB bandit + P3 集成）。
- 不修改 compact model（已独立配置为 `deepseek-v4-flash`）。
- 不修改 `mimo` / `mimo-pro` 的现有路由配置（`code_edit`、`risky_refactor` 仍走 `capable`）。
- 不创建新的 `ModelCapabilityCard`（DeepSeek Flash 的 card 已在 `src/main.tsx` 中创建）。

### 任务 3：Coordinator 接入探索预算校验

**目标：** 当 scope 设置了 `maxFiles` 或 `maxTokens`，Coordinator 在分发探索型 worker 前校验预算，超出时拒绝并给出明确信号。

**步骤：**

- [ ] **步骤 1：在 `selectModelForTask` 后、worker 执行前插入预算校验**

  在 `src/agent/coordinator.ts:204` `const task = mapWorkOrderKindToCapabilityTask(order.kind)` 之后，`const selected = this.selectModelForTask(task)` 之前，插入：

  ```ts
  // Scope budget check for exploration workers
  if (order.kind === 'code_search' || order.kind === 'doc_research' || order.kind === 'plan') {
    const scope = order.scope
    if (scope.maxFiles !== undefined && (scope.files?.length ?? 0) > scope.maxFiles) {
      return {
        status: 'completed',
        order,
        results: [{
          workOrderId: order.id,
          status: 'blocked',
          summary: `Scope budget exceeded: ${scope.files!.length} files exceeds maxFiles=${scope.maxFiles}`,
          findings: [],
          artifacts: [{ kind: 'risk', title: 'Scope budget exceeded', content: `Requested ${scope.files!.length} files but maxFiles=${scope.maxFiles}` }],
          changedFiles: [],
          risks: [`scope budget: ${scope.files!.length} > ${scope.maxFiles} maxFiles`],
          nextActions: ['Reduce file scope or increase maxFiles budget'],
          evidenceStatus: 'blocked',
        }],
        packet: buildPrimaryWorkerPacket([]),
      }
    }
  }
  ```

  注意：`maxTokens` 预算校验需要知道当前上下文实际 token 用量，这在 worker 启动前不可得。Phase 1 只做 `maxFiles` 校验；`maxTokens` 字段保留给后续 worker session 内的运行时检查。
