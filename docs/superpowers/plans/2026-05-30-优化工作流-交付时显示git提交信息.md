# 交付时显示 Git 提交信息 实现计划

> **面向 AI 代理：** 使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 优化工作流，交付时回复内容包含 git 提交编号和摘要，会话内 git 提交信息可检索留存

**架构：** 扩展 SessionStateManager 存储会话内 git 提交记录，修改 deliver-task.ts 在 commit 成功后记录提交信息并在交付报告中显示，提供检索接口让用户可以查看会话内的所有提交

**技术栈：** TypeScript, Node.js child_process, SessionStateManager

---

- **SessionStateManager** - 存储会话状态（需要扩展）

两个子系统紧密相关，可以在一个计划中完成。

## 3. Research endorsement

### 3.1 SessionStateManager 现状

**调用者：**
- `src/agent/loop.ts` - AgentLoop 使用 SessionStateManager 跟踪会话状态
- `src/prompt/volatile-block.ts` - 渲染 volatile block 时调用 renderForVolatile()

**存在原因：**
- 提供跨 turn 的文件、决策、验证状态感知
- 渲染紧凑的 XML 块注入 volatile block

**边缘情况风险：**
- 提交数量过多会导致 volatile block 超过 500 字符限制
- 需要限制存储的提交数量（建议最多 10 个）

### 3.2 deliver-task.ts 现状

**调用者：**
- AgentLoop 通过工具注册调用
- 用户通过 `deliver_task` 工具调用

**存在原因：**
- 检查交付就绪状态（GREEN/YELLOW/RED）
- 执行 ownership-scoped commit

**边缘情况风险：**
- commit 成功后需要立即获取提交 hash
- 如果 git 命令失败需要优雅处理

```typescript
// 记录一次 git 提交
recordCommit(entry: GitCommitEntry): void {
  this.state.gitCommits.push(entry)
  // 限制最多存储 10 个提交
  if (this.state.gitCommits.length > 10) {
    this.state.gitCommits = this.state.gitCommits.slice(-10)
  }
  this.state.updatedAt = Date.now()
}

// 获取所有提交
getCommits(): readonly GitCommitEntry[] {
  return this.state.gitCommits
}

// 获取最近 N 个提交
getRecentCommits(count: number): GitCommitEntry[] {
  return this.state.gitCommits.slice(-count)
}
```

2. 在 `execute` 方法中，commit 成功后记录提交信息：

在 `if (commit)` 块中，commit 成功后添加：
```typescript
if (commitResult.ok) {
  // 获取提交的 hash
  const hashResult = spawnSync('git', ['rev-parse', 'HEAD'], { 
    cwd: params.cwd, 
    encoding: 'utf-8', 
    timeout: 5000 
  })
  
  if (hashResult.status === 0) {
    const fullHash = hashResult.stdout.trim()
    const shortHash = fullHash.slice(0, 7)
    
    // 记录到 SessionStateManager
    ctx.sessionStateManager?.recordCommit({
      hash: fullHash,
      shortHash,
      message: message!,
      files: report.ownedFiles,
      timestamp: Date.now(),
    })
    
    // 在输出中显示提交信息
    lines.push('', `✅ Scoped commit created with message: "${message}"`)
    lines.push(`   Files: ${report.ownedFiles.join(', ') || '(none)'}`)
    lines.push(`   Commit: ${shortHash}`)
  }
}
```

3. 添加辅助函数获取提交信息：
```typescript
function getCommitInfo(cwd: string): { hash: string; shortHash: string } | null {
  const result = spawnSync('git', ['rev-parse', 'HEAD'], { 
    cwd, 
    encoding: 'utf-8', 
    timeout: 5000 
  })
  if (result.status !== 0) return null
  const hash = result.stdout.trim()
  return { hash, shortHash: hash.slice(0, 7) }
}
```

**测试：**
