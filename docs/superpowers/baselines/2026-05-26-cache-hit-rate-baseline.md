## 当前架构的缓存保护机制（已生效）

| 机制 | 状态 | 效果 |
|------|------|------|
| Trailer mode（fresh↦最后 user msg） | ✅ | Turn 1+ 稳定在 92%+ |
| CachedFreshBlock（同 msg 内复用） | ✅ | 同一 user msg 的连续 tool-call 几乎不 miss |
| Frozen volatile base（不随 turn 变化） | ✅ | 历史消息 prefix 不变 |
| 1M+ skip observation masking | ✅ | 避免旧消息内容被替换 |
| 1M+ skip regular compaction | ✅ | 避免大规模历史重写 |
| 86% proactive session split | ✅ | 避免逼近 95% ceiling |
| Habituation promotion → consolidated | ✅ | 稳定字段不污染 frozen prefix |
