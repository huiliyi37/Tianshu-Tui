## 项目经历

### 天枢（Tiānshū）— 模型认知增强运行时（CVM）· 终端 Coding Agent

**角色**：架构师 / 全栈工程师（独立开发）
**周期**：2026.05 — 至今（29 天核心建设期，2,178 commits，日均 75 次提交，无间断）
**规模**：91,551 行 TypeScript 源码 + 86,012 行测试（601 文件，5,698 用例）

**一句话概述**：为 DeepSeek V4 建造了一套认知增强运行时（Cognitive Virtual Machine），通过 19 个 hook × 5 个认知 phase 的 trap-and-emulate 管线，在运行时层面拦截并修正 RLHF 训练带来的 sycophancy、注意力衰减、锚定等行为退化。A/B 对照实验（DeepSeek-V4-Flash，第三方审查）证实：同一套模型权重在有/无 CVM 时，任务完成率从 80% 提升到 100%，主动质疑率从 0/5 提升到 3/5。Synced with XiaomiMiMo/MiMo-Code

**核心职责与技术产出**：

**1. CVM 认知虚拟机架构设计与实现**
- 基于 10 个无关领域（胚胎学/虚拟机理论/宪法学/感觉替代/生物圈 2 等）的跨学科收敛，设计 CVM 六层架构（信念宪法 → Courage Hook → Domain Voice → Sensorium → Hook Pipeline → Tool Interfaces）
- 将 6 类模型训练偏差（锚定/sycophancy/注意力衰减/幻觉/过度服从/模式僵化）映射为可被运行时拦截的"特权指令集"
- 验证了 CVM 可通过 SFT 融入模型权重：nanoGPT(85M) → Qwen2.5-0.5B(LoRA, 6min, <¥1) → Qwen2.5-7B，格式准确率 100%，模型学会了"知道自己不知道"

**2. Prefix Cache 极致优化（56% → 99.6%）**
- 系统性猎杀 8 个 Cache Killer（semantic pruning 改写历史消息、observation masking、文件去重替换、磁盘预算截断、frozen 区被 habituation 改写等），建立 Frozen Base + Working + Append-only Appendix 三区缓存布局
- 提炼两条字节级不变量：历史消息内容不可修改、消息数组只追加不重排
- 稳态命中率 99.6%，在 50 倍价差（hit ¥0.0028 vs miss ¥0.14 / 1M tokens）下实现约 97% 成本降低

**3. Agent Loop 退化检测与恢复**
- 多信号收敛检测器：工具调用序列指纹匹配（精确指纹 + bash 命令类归并）、振荡惩罚、Vigor 执行能量追踪（tonic/phasic/curiosity）
- Cognitive Mirror 每轮注入模型自身状态快照（stability/pressure/confidence），让模型感知自身状态
- Doom loop 在 3-5 个 turn 内被识别并打断，自动进入保护模式

**4. 多模型并发协调系统**
- 文件归属权 + 语义锁（SQLite SessionRegistry）+ 声明锁（acquire/release/check/reap_stale）
- 压力峰值实测：37 小时 154 commits、213 文件、零冲突零回退；同秒 3 个 session 并发提交；峰值 17 commits/小时
- 5 个模型（GPT 5.5 / DeepSeek V4 / MiMo V2.5 / GLM 5.1 / Claude Opus）在平台上长期协作，文件归属、信息素记忆与语义锁保证互不踩踏

**5. Verification Pipeline 与交付门禁**
- 三级验证（TypeCheck → Related Tests（import graph 追踪）→ Full Suite）+ 证据追踪 + 自动归因（己方/外部）
- 交付门禁内置自动接线审查（wiring reviewer）：从项目真实生产入口正向追踪到改动点，机械地抓出"写而不读"的死接线
- 审查基础设施失败时如实报告 "review DID NOT run"，不做伪 verified

**6. Sub-Agent 编排与成本感知路由**
- delegate_batch 并行 2-5 个 worker，隔离 worktree 执行，聚合策略 all_required/majority/first_success
- Flash→Pro 故障升级：默认低成本 Flash 执行，失败自动升级 Pro 重试（每会话限额防成本爆炸），bandit 晋升决策
- Worker 活性监控：liveness 心跳 + 停滞扫描 + 等差超时阶梯

**7. 上下文压缩与记忆系统**
- 六策略分层压缩（语义裁剪/微压缩/过时轮次检测/动态密度调节/阈值触发/关键 claim 跨 session 持久化）
- Stigmergy 信息素跨会话记忆：文件级信息素自动沉积与衰减，跨 session 越用越熟
- 在 1M 窗口模型上压缩与缓存冲突时，缓存优先

**8. A/B 实验基础设施**
- 建立了完整的 A/B 对照实验体系（STAR_SOUL=0/1），包含 5 个任务的隐藏风险设计、预期行为差异表、量化判定标准
- 完成 A/B 实验执行与第三方审查，产出 5 个任务的逐项对比分析与信念条目逐条验证

**9. 自举建造**
- 项目约 80% 的代码与设计由天枢自己的 agent 在天枢平台上迭代演进而来
- 人类承担方向、架构决策与最终验收；agent 自主执行、自省、修复、交付
- 子项目验证：3 个 agent 在天枢上从零构建了 Rust 版编码 agent"伏羲"（8,200 行 Rust，205 测试全过）

## 技术栈

```
语言：       TypeScript (strict mode, noUncheckedIndexedAccess)
运行时：     Node.js 22+
TUI 框架：   Ink 6 (React) + 自研 T9 UI（ANSI 终端渲染引擎）
构建：       tsup (ESM bundle)
测试：       node:test + node:assert/strict（5,698 用例）
数据库：     SQLite (better-sqlite3) — SessionRegistry、声明锁、Claims 持久化
API 协议：   SSE (Server-Sent Events) 流式 + OpenAI 兼容 / Anthropic native / Codex OAuth
模型：       DeepSeek V4 / GPT 5.5 / MiMo V2.5 Pro / GLM 5.1 / Claude Opus
缓存策略：   DeepSeek V4 exact-prefix cache（字节级优化，99.6% 命中率）
进程隔离：   Git worktree（子代理写入隔离）
版本控制：   Git（原子提交纪律，显式列文件，禁 git add -A）
```
