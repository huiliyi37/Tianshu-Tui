# v2.19.3 迭代记录

> 日期：2026-07-15

## sidecar 启动可靠性（重点修复）

针对部分用户反馈「sidecar 启动失败」做了全链路加固：

- **启动顺序调整**：sidecar 先完成 `/health` 监听，再初始化 agent / MCP 等重型组件——冷启动不再因初始化慢导致 Rust 健康探测 15 秒超时误判失败。
- **/health 免鉴权**：健康探测端点去掉 Bearer token 要求，避免探测请求因 token 时序问题被拒。
- **启动失败可见性**：`ready` 状态为 undefined（旧 shell 或异常）时也显示致命横幅，不再静默吞掉错误；监控器对首次 spawn 失败增加重试。
- **网络请求超时**：前端 `rivetFetch` 加 15 秒默认超时，防止 sidecar 未就绪时请求永久挂起。

## MCP 连接器与 OAuth

- **OAuth 框架**：新增 OAuth 连接器（Google Drive、Microsoft 365 等），支持令牌获取、自动刷新与持久化。
- **并发 OAuth 流程**：共享 callback server 支持同时进行多个 OAuth 授权，互不阻塞。
- **MCP 热注入**：连接器启用后工具热注入会话，无需重启；删除连接器清理状态不再泄漏。
- **MCP 日志**：新增环形日志缓冲 + 持久化 stderr，`/mcp logs` 可查看连接器输出。
- **静态工具禁用**：配置级禁用指定工具（cache-safe，不影响前缀缓存）。
- **transport 抽象**：提取 transport-factory + 重连状态机，stdio 与 SSE 连接器统一管理。

## 桌面端交互重做

- **三栏信息架构**：对齐 Codex 设计语言，Workspace / Changes / Review 三区布局重组。
- **Changes 面板**：分层 Overview + 单文件 Review 流，过滤运行时生成的文件，支持手动 checkpoint。
- **Ask 模式**：新增 Ask 模式，澄清卡片对齐，内联 chat diff。
- **浏览器 & computer-use 闭环**：补全截图→反馈→重试工作流。
- **文件路径交互**：会话区文件路径支持 Ctrl/Cmd+单击在右侧文件浏览器展开。
- **原生文件附件**：使用原生文件对话框 + @file 提及上传附件。
- **聊天滚动修复**：向上滚动时停止回弹抖动；容器宽度变化时清理虚拟列表高度缓存。
- **更新横幅**：错误处理与重试改进；dev 模式下跳过自动更新检查。

## prompt 工程

- **事实锚点融入**：事实锚点核对融入 evidence-scope，消费面穷尽融入 lossy-observation-discipline。
- **静态缓存失效警告**：启动时打印静态 prompt P1+P2 缓存失效警告（CLI），中文提示。
- **委派与收敛细节**：恢复 static.ts 中委派与收敛的操作细节。
- **baseline 工程纪律**：通用工程纪律回归 baseline 段全局继承（华盖星域精简）。

## 构建与发布流程

- **tsconfig 升级**：Node16 → NodeNext，匹配 Node 24 运行时目标；修复 tsc 假绿灯。
- **Windows release 脚本**：新增 `scripts/build-windows-release.sh`，覆盖版本校验、签名私钥检查、NSIS/MSI 构建、产物收集、`latest.json` 增量合并。
- **macOS release 脚本**：`build-macos-release.sh` 收集 `.sig` 签名文件并自动更新 `latest.json` darwin 条目。
- **单架构打包**：macOS 按目标架构单独打包 Node/native 依赖，减小包体。
- **版本号对齐**：`Cargo.toml` 从 `0.0.1` 对齐到 `2.19.3`，与 `tauri.conf.json` / `package.json` 一致。
- **pre-push 类型检查**：新增 auto-installed pre-push typecheck gate。
- **产物清理**：release 产物、日志、插件目录等加入 `.gitignore`。

## 其他修复

- **edit_file 假性 hang**：Windows 下 esbuild 同步加载阻塞事件循环导致 edit_file 卡顿，已修复。
- **pointer guard**：收紧指针守卫与 hash_edit 语义。
- **Authorization header**：恢复被 rivetFetch timeout 合并丢掉的 Authorization header。
- **runtime_info 缓存**：app mount 时清除缓存的 runtime_info token；browser-dev fallback 不再缓存失败结果。
