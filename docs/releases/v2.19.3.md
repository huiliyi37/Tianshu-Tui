# v2.19.3 迭代记录

> 日期：2026-07-15

## 维护与发布流程

- **桌面端 dev 模式**：`UpdateBanner` 在 `import.meta.env.DEV` 下跳过自动更新检查，避免 `target/debug` 二进制版本 stale 时反复弹横幅。
- **版本号对齐**：`desktop/src-tauri/Cargo.toml` 从 `0.0.1` 对齐到 `2.19.3`，与 `tauri.conf.json` / `package.json` 保持一致。
- **Windows release 脚本**：新增 `scripts/build-windows-release.sh`，覆盖版本校验、签名私钥检查、NSIS/MSI 构建、产物收集、`release/latest.json` 增量合并。
- **macOS release 脚本升级**：`scripts/build-macos-release.sh` 现在会收集 `.sig` 签名文件，并在打包后自动更新 `release/latest.json` 的 darwin 条目。
- **构建产物清理**：将 `release/*.dmg`、`release/*.app.tar.gz`、`release/*.sig`、`logs/`、`.rivet/plugin-*/`、`.rivet/scratch/`、`Library/` 等运行时/构建产物加入 `.gitignore`。

## 用户可见修复

- 桌面端开发环境下不再误报「新版本可用」。
- release 打包脚本内置版本一致性硬闸门，减少因版本号不同步导致的自动更新循环。
