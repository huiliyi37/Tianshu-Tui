# v2.19.2 迭代记录

> 日期：2026-07-15

## ⚠️ 升级必读：旧会话前缀缓存将碎裂

本次更新精简了 static prompt 基座（`src/prompt/static.ts`），导致 frozen 前缀的字节从第一行起发生变化。

- **已打开的会话**在升级后继续发送消息时，下一轮会触发**完整前缀缓存 miss**，产生一次性全量 cache creation tokens。
- cache creation 成本显著高于 cache read（DeepSeek V4-PRO 上约 120 倍价差），长对话尤其明显。
- **建议操作**：升级后请新建会话，不要在旧会话标签页/窗口中继续长对话。旧会话历史可读，但继续交互会承担额外 token 成本。

CLI 端没有图形化更新弹窗，请手动以新会话启动；桌面端会在升级后首次启动时弹出本说明。

## 功能变更

### 1. Static Prompt P1+P2 精简

- 合并 `lossy-observation-discipline` 到 `evidence-scope`，消除重复规则。
- 压缩 `<tool-usage>` 中的三层收敛纪律为一句话。
- 删除独立 `<delegation>` 区块，将委派纪律合并到 `<tool-usage>`。
- 删除 `<delivery-contract>` 中与 `<beliefs>` 重复的「异议推进」子条款。
- 体积：约 11,800 字符 / 224 行 → 10,300 字符 / 186 行，减少约 12%。

### 2. MCP 四波改动合入（W1–W4）

- **W1**：transport-factory 抽象 + reconnect 状态机。
- **W2**：OAuth 连接器框架（PKCE + 4 provider registry）。
- **W3**：config 级静态工具禁用（缓存安全）。
- **W4**：LogRingBuffer + 持久化 stderr + `/mcp logs`。

详见 `docs/changelog/2026-07-15-static-prompt-p1p2-reduction.md` 与相关提交。

## 维护说明

- CLI、桌面端与 release manifest 同步升至 `v2.19.2`。
- 升级后新建会话即可获得稳定的 prefix-cache 基线。
