## 3. P4-a gated bandit 审查存档（供天权复用为 gated 模板）

`a6e0422` 的闸是目前主线最严的 gated 实现，**收官-2/P4-d 的 gated 启用建议直接复用这套门**：

7 道串联证据门（任一不过即 shadow-only）+ 人工 flag：
1. `MIN_TOTAL_SAMPLES=30` 2. `MIN_ARM_SAMPLES=5` 3. `REWARD_MARGIN≥0.05` 4. **`MAX_FALSE_GREEN_RATE=0`（零容忍）** 5. `MIN_RULE_AGREEMENT≥0.80` 6. `hardGateSafe && 候选≤规则并行` 7. `featureFlagEnabled`（默认 false）

两条关键安全性质：
- **flag 默认关**：gate 可"开"（证据足）但 flag 关时 `applied:false`，仍只 shadow。双层门=证据门+人工开关。
- **down-only 钳制**：`min(rule, candidate, 5)`，bandit 只能让 team 更保守，**结构上不可能引入并行写冲突**，最坏只是"白白慢一点"。`ruleParallelism` 来自 `wave.parallelLimit`（groupTeamTasks 产出），守住天权「bandit 只在安全集合内调参，不替代 groupTeamTasks」。
