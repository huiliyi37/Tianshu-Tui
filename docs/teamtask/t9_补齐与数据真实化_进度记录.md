## 如何切换

当前默认入口仍是 `main.tsx`（React/Ink TUI）。T9 ANSI TUI 入口为 `main-ansi.ts`。

**临时试用**:
```bash
npx tsx src/main-ansi.ts
```

**永久切换**（需改 tsup.config.ts + package.json）:
1. `tsup.config.ts`: `entry: ['src/main.tsx']` → `entry: ['src/main-ansi.ts']`
2. `package.json`: 确认 bin 指向 `dist/main.js`（构建后自动生成）

建议先通过 `RIVET_T9=1` 环境变量做灰度切换，再改构建入口。
