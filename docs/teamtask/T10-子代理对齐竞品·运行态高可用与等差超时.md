>
> **A4 修正**：batch 是 `Promise.all(inflight)`（`coordinator.ts:700`），sweep **不能**直接 abort 共享 signal——须给**每个 order 独立 `AbortController`**，stall 时 abort 该 worker，其 `processNext` 走 catch 落 `workerFailureResult`，`Promise.all` 不受影响。sweep 的 `setInterval` 必须 `.unref()` 防进程悬挂。
>
> **A5 修正**：初版/已提交（`605e6cf`）只测了 `classifyFailure`（已有纯函数）+ `makeFaultClient`（测试自造 helper）+ `makeWorkerConfig`（fixture）——**没一个跑 `runWorkerSession`**，生产 retry/abort 逻辑零覆盖（自测自的虚假绿）。新方向：让 `runOnceWithTransientRetry` 可注入 mock `agent`（它只依赖 `agent.run`），在**不启动完整 AgentLoop** 下测到真实 retry→blocked 路径。
>
> **R3/R5 已提交死代码待清理（独立 commit）**：`WORKER_SSE_IDLE_MS`/`SSE_IDLE_MS`（删或接 client）、`HARD_STALL_MS`（让 `loop.ts` 导入消双源）、`capBudgetAtTool`+coordinator 的 `toolTimeoutMs` unused import（删或把接口第三参数补全打通）、`worker-fault-injection.test.ts`（补真实 `runWorkerSession` 覆盖）。**顺手开 `tsconfig` 的 `noUnusedLocals`**，这类死 import 以后编译即挡。
>
> **设计总纲（贯穿 A2/A3/A4）**：worker 该因「卡住不动（静默）」被收，**绝不该因「干得久」被收**。可观测（A2）做到后，杀的依据从「墙钟时间」换成「静默时长」，时间帽退居远兜底。Cursor 子代理能多轮深查正因其 `is_background` 异步、父不阻塞——故 **B2 异步化升入 Track A 思路**（见 B2）。

**目标：** 让 Rivet 的子代理在「运行态可观测性 + 生命周期」上对齐 Cursor / Claude Code，并先于对齐补强一条**运行态高可用彻查**——把已存在但未接通的健康设施（provider-health、worker 心跳、超时梯）从「半接 / 死接线」状态接成端到端闭环，消除子代理「断连、卡死、超时不自洽」。

**架构：** 两条并行 Track。
- **Track A（运行态高可用，本轮重点）**：复活 provider-health 死接线 → 打开 worker 心跳黑盒 → 重构为**等差 + 自洽**的超时梯 → 加 in-flight worker stall 探测 + escalation → 建断连/卡死 fault-injection 测试底座。
- **Track B（生命周期对齐竞品）**：resume 续跑接线 → 后台/异步子代理 → 嵌套策略定调 + depth cap → profile description 自动选择 → `/agent-name` 直调。

**技术栈：** Node.js 22+ / TypeScript strict / `node:test` + `node:assert/strict` / ESM（import 带 `.js`）/ 不可变模式。测试镜像源码结构 `src/**/__tests__/*.test.ts`。

### 0.4 运行态短板清单（全部 code-verified，file:line）

- **R1 provider-health 死接线**：`ProviderHealthTracker` 生产代码从不 `new`（仅 `provider-health.ts:198` 的 `fromJSON` 静态 + 测试）。`main.tsx` 构造 `DelegationCoordinator` 未传 `providerHealth`，故 `coordinator.ts:203` 的 skip-cold 永远 `undefined` no-op。coordinator 也从不调用 `recordSuccess/recordFailure`（grep 0 命中）→ 健康分永不更新。**整套 Physarum 路由是装好但没插电的设备。**
- **R2 worker 心跳黑盒**：`worker-session.ts:70` 的 `runOnce` 回调集**没有** `onPhaseChange`/`onHeartbeat`。worker 内 `AgentLoop.initializeRun` 仍构造 `TurnHeartbeat`（`loop.ts:1234`，hardStall 240s）能掐死 wedge，但其 liveness 信号 fire 进虚空——父 coordinator 与 UI 无法区分「170s 在深读」与「卡死」。
- **R3 超时梯不自洽 + 非等差**：四层互相错位——
  - SSE idle（`openai-client.ts:61-67`）：reasoning-first-byte 90s / reasoning-read 180s / slow-first-byte 180s / slow-read 300s；maxStream 10min（`:374`）。codex thinking-stall 90s / idle 300s。
  - worker budget.timeoutMs（`work-order.ts:251/292`）：读/写均默认 **180s**。
  - tool 级 progressive（`delegate-task.ts:41` = 30/75/180s；`delegate-batch.ts:79` = 45/90/180s）。
  - heartbeat hardStall（`loop.ts:1237`）：**240s**。
  - **矛盾**：worker budget(180s) < SSE slow-read(300s) → 合法慢读会被 budget 先掐；tool(30-180s) 可短于 worker budget(180s) → tool 超时经 `wrapAbort`(`coordinator.ts:422`) reject 把 worker 半途掐断。且 30→75→180、45→90→180 **都不是等差数列**（用户明确要等差）。
- **R4 无 in-flight stall 探测**：coordinator 派发后纯 `await`，除 worker 自身 240s 看门狗外，父侧无「该 worker 是否还在产 token」的探测；卡死只能等 budget 或 hardStall 兜底。
- **R5 断连恢复无回归测试**：`worker-session.ts:100` 有 `runOnceWithTransientRetry`（2 次,指数退避,覆盖 `timeout/flaky/api_error`），但无 fault-injection 测试证明 ECONNRESET / idle-stall / 429 路径真的触发 retry→abort→escalation。

    const providerId = (workerConfig as { providerId?: string }).providerId

    try {

  onActivity?: (kind: 'text' | 'thinking' | 'tool_use' | 'tool_result') => void,

    onError: (error) => { transcript.errors.push(error.message) },
    onAbort: () => { transcript.errors.push('Worker aborted') },

```typescript
export interface WorkerLivenessOptions {
  /** No activity for this long ⇒ worker is considered stalled. */
  stallMs: number
  /** Injectable clock for tests. */
  now?: () => number
}

/** Tracks last-activity time per in-flight worker so the coordinator can
 *  detect a worker that stopped producing tokens BEFORE its budget/hardStall
 *  fires — turning a 180s frozen session into an early, observable abort. */
export class WorkerLiveness {
  private readonly stallMs: number
  private readonly now: () => number
  private readonly lastActivity = new Map<string, number>()

  constructor(opts: WorkerLivenessOptions) {
    this.stallMs = opts.stallMs
    this.now = opts.now ?? Date.now
  }

  register(id: string): void { this.lastActivity.set(id, this.now()) }
  tick(id: string): void { if (this.lastActivity.has(id)) this.lastActivity.set(id, this.now()) }
  unregister(id: string): void { this.lastActivity.delete(id) }

  /** Ids whose silence exceeds stallMs. */
  stalled(): string[] {
    const t = this.now()
    const out: string[] = []
    for (const [id, last] of this.lastActivity) {
      if (t - last > this.stallMs) out.push(id)
    }
    return out
  }
}
```

- 给**每个 order 独立一个 `AbortController`**（`per-order`，存 `Map<orderId, AbortController>`），把它的 `signal` 作为 `wrapAbort`/`workerConfig.abortSignal` 传给该 worker（与父 `config.abortSignal` 用 `AbortSignal.any([...])` 合并，父 abort 仍能全杀）。

import type { StreamClient, StreamCallbacks } from '../../../api/stream-client.js'
import type { OaiChatRequest } from '../../../api/oai-types.js'

type Fault =
  | { kind: 'econnreset' }
  | { kind: 'idle_stall' }          // never resolves until signal aborts
  | { kind: 'rate_limit' }          // 429 then recover
  | { kind: 'ok'; text: string }    // emit text + stop

/** A StreamClient whose behavior is a scripted queue of faults — one entry
 *  consumed per stream() call — so tests can assert retry/abort/escalation
 *  paths deterministically without real network. */
export function makeFaultClient(script: Fault[]): StreamClient {
  let i = 0
  return {
    async stream(_req: OaiChatRequest, cb: StreamCallbacks, signal?: AbortSignal): Promise<void> {
      const fault = script[Math.min(i++, script.length - 1)]
      switch (fault.kind) {
        case 'econnreset':
          throw new Error('ECONNRESET socket hang up')
        case 'rate_limit':
          cb.onRateLimit?.(10)
          throw new Error('HTTP 429 Too Many Requests')
        case 'idle_stall':
          return new Promise<void>((_resolve, reject) => {
            if (signal?.aborted) return reject(new Error('aborted'))
            signal?.addEventListener('abort', () => reject(new Error('aborted')), { once: true })
            // never resolves on its own — simulates a wedged stream
          })
        case 'ok':
          cb.onTextDelta(fault.text)
          cb.onContentBlock({ type: 'text', text: fault.text } as never)
          cb.onStopReason('stop', {})
          return
      }
    },
  }
}

/** Read a previously persisted worker result for resume/inspection.
 *  Returns null if absent or unparseable — callers must handle a cold miss. */
export function loadPersistedResult(orderId: string, homeDir = homedir()): WorkerResult | null {
