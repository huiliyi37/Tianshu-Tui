# T9 对话渲染流畅化（P0：消除滚动卡顿）

## 背景与范围

T9 是全新的纯 ANSI TUI 路径（`src/tui/engine/`），与旧 React/Ink `app.tsx` 面板并行，本计划只动 T9。切分逻辑（`stream-renderer.ts` 的 commit-prefix / live-tail split）已正确实现，**问题不在切分，在底部 live 区的重绘协议**。

## 根因假设（静态读码定位，阶段 0 runtime 复现确认）

核心文件 [src/tui/engine/live-engine.ts](src/tui/engine/live-engine.ts)：

- **R1（主因）尾行 `\n` + `SAVE_CURSOR`/`RESTORE_CURSOR` 贴底失效**（第 92-135 行）：每行含 `\n`，光标停在 live 区下方；live 区贴底后尾行 `\n` 触发终端滚动，而 `\x1B[s`/`\x1B[u` 是绝对坐标，滚动后跳回错误行 → 错位累积 → "不停滚 / 卡顿"。解释了"对话一会儿后才卡"。
- **R2 无行级 diff，每帧 `ERASE_SCREEN_END` 全擦重写**（第 110-135 行）：`lineCache` 已存上一帧却未用于 diff；120ms ticker（[app.ts](src/tui/engine/app.ts) 第 523-535 行）每秒约 8 次整区擦写，spinner 帧变化也全擦 → 闪烁。
- **R3 commit-while-streaming 交错**：每个稳定边界走 `commitAbove`（[app.ts](src/tui/engine/app.ts) 第 508-512 行）= 擦 live → 写 scrollback → 整区重画。

## 修复方向（对标成熟实现）

aider `mdstream.py`(live_window=6) / ink 6.8.0 `log-update` `createIncremental` 的共同协议：**不用 SAVE/RESTORE、光标常驻 live 区、相对光标定位、尾行不带 `\n`、行级 diff 跳过未变行、CSI 2026 同步输出包裹整帧**。

## 阶段

### 阶段 0 — runtime 复现 + 确认根因（前置，不改产品代码）
- 写一个最小 harness（node 脚本 + 真 TTY 或 mock `WriteStream`）：构造 LiveEngine，注入 N 帧 + 触发 commit，断言/观察是否出现尾行 `\n` 滚动 + SAVE/RESTORE 错位。
- 或加临时 `RIVET_DEBUG_LIVE=1` instrumentation 统计每帧写入的转义序列。
- 产出：确认 R1/R2/R3，或修正假设。**复现脚本要能 RED（重现卡顿特征），修复后转 GREEN。**

### 阶段 1 — 重写 LiveEngine 重绘协议（核心，解决 R1）
- 去掉 `SAVE_CURSOR`/`RESTORE_CURSOR`。光标常驻 live 区，渲染后停在**最后一行末尾**（尾行不写 `\n`）。
- 渲染协议：`cursorUp(lastDisplayRows - 1)` 回 live 区顶行 → 逐行 `\r` + erase + 内容，行间 `\n`，**末行不带 `\n`** → 下一帧再 cursorUp 回顶。
- 同步改 `clearForCommit()` / `clear()` / 首帧 append 路径，保持 display-row(wrapping) 计数一致。
- 门控：`tsc --noEmit` + 阶段 0 复现脚本转 GREEN。

### 阶段 2 — 行级 diff（解决 R2）
- 用 `lineCache` 对比新旧帧，未变行 `cursorDown` 跳过不重写；spinner 帧变化只重写状态行。对标 `createIncremental`（跳过未变行）。
- 门控：复现脚本断言"仅 spinner 行变化时不重写其余行"。

### 阶段 3 — CSI 2026 同步输出防撕裂（解决残余闪烁）
- 在 [src/tui/engine/ansi.ts](src/tui/engine/ansi.ts) 加 `\x1B[?2026h` / `\x1B[?2026l`，每帧整帧写入用其包裹。
- 门控：复现脚本断言每帧被同步序列包裹。

### 阶段 4 — 验证
- 真终端手验（必须，滚屏类 bug 单测覆盖不了）：tmux / VS Code 终端各跑一次，agent 输出 >终端高度的长回复，流式中不持续滚屏、输入行不抖、scrollback 完整。
- 新增 `src/tui/engine/__tests__/live-engine.test.ts`：mock stdout 断言协议（无 SAVE/RESTORE、尾行无 `\n`、line-diff 跳过未变行）。
- 全量 `npm test` + `npm run typecheck` 绿。
