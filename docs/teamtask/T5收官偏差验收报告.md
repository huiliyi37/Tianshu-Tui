## 开关策略

1. `teamSchedulerBanditEnabled`: **继续默认 false**。只有当 `team_scheduler_shadow:*`、`team_scheduler_reward:*` 与 `team_scope_health:*` 达到最低样本且无 false-green/high scope leak 时，才允许人工 opt-in。
2. `modelTierBanditEnabled`: **继续默认 false**。必须同时满足 reward 样本足够、hardFloor veto 正常、无 false-green、ScopeHealth observed-first 证据明确，才允许人工 opt-in。
3. `modelRoutingGatedEnabled`: **继续默认 false / shadow-only**。ModelG 只能产出推荐审计，不切主控模型。
4. `PlanCacheAdvisory`: **继续 advisory-only**。命中可以进入动态提示，不 JIT、不执行缓存步骤。
5. `Physarum supervision`: **继续单向学习**。监督边可以写入学习图，但不得反向影响 scheduler。

## 继续观测项

- 补齐真实运行样本后重新运行 `evaluateGatedInfluenceHistory()`，重点看：
  - `gateOpenCount` 与 `appliedCount` 分离；
