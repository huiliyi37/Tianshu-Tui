▌ 流式输出能不能做成可中断的?按 esc 停下当前生成,但已经渲染出来的内容要保留,别整段清掉。
·

可以。核心是给流读取套一个 AbortController,esc 触发 abort(),在 catch 里识别中断信号后停止追加而非清空缓冲。先看现有实现落在哪。

bash grep -rn "for await" src/stream/
src/stream/reader.ts:42 for await (const chunk of resp.body) src/stream/render.ts:11 for await (const tok of source)
✓ 2 matches · 0.18s
·

循环在 reader.ts。把 signal 透传给 fetch,并在循环顶部检查 signal.aborted 提前 break——已渲染的 token 自然留存。

edit src/stream/reader.ts
42 - for await (const chunk of resp.body) { 42 + for await (const chunk of resp.body) { 43 + if (signal.aborted) break; // 保留已渲染内容
