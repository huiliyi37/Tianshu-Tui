## Completed

### v0.1 Baseline
- **Architecture**: Ink 6 + React 19 TUI, Anthropic-compatible SSE client, multi-turn agent loop, SHA-256 cache fingerprinting, 3-layer compaction
- **DeepSeek V4**: thinking mode, truncated JSON recovery, tool JSON content fallback, usage normalization, volatile injection via independent user msg
- **Tools (4→6)**: read_file, write_file, edit_file, bash, **grep**, **glob**
- **System prompt**: ~3800 tokens, per-tool prompts with usage examples
- **Commands**: /help /exit /compact /model /sessions /resume /clear

### Phase 1: Performance Optimization
- **Non-blocking git status**: Async execFile + stale-while-revalidate cache, zero event loop blocking
- **Render batching**: 50ms batched flush for text, thinking, and tool output (~20fps)
- **Incremental token accounting**: O(1) per-turn via SessionContext, avoids O(N*M) rescans
- **Smart compact wired**: LLM-based summarization with micro-compact fallback, compactClient in main.tsx
- **Fingerprint full tool definitions**: Detects description/schema changes, not just name changes
- **Provider capability gate**: Tool JSON fallback only for providers with the bug
- **Abort-aware retry**: abortableDelay rejects immediately on signal, no wasted wait
- **TUI log-state**: Pure function helpers eliminate duplicate tool cards

### Phase 2: Dev Capability
- **grep tool**: ripgrep-first strategy with Node.js native readline fallback, regex/literal, glob filter, .gitignore-aware
- **glob tool**: ** recursive, * wildcard, ? single-char, {a,b} brace expansion, 500 result cap, excludes node_modules/.git/dist
