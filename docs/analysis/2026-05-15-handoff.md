## Completed

### v0.1 Baseline
- **Architecture**: Ink 6 + React 19 TUI, Anthropic-compatible SSE client, multi-turn agent loop, SHA-256 cache fingerprinting, 3-layer compaction
- **DeepSeek V4**: thinking mode, truncated JSON recovery, tool JSON content fallback, usage normalization, volatile injection via independent user msg
- **System prompt**: ~3800 tokens, per-tool prompts with usage examples
- **Commands**: /help /exit /compact /model /sessions /resume /clear /rollback

### Phase 1: Performance (7/7)
- **Non-blocking git status**: Async execFile + stale-while-revalidate cache
- **Render batching**: 50ms batched flush for text/thinking/tool output (~20fps)
- **Incremental token accounting**: O(1) per-turn via SessionContext
- **Smart compact wired**: compactClient in main.tsx, LLM summarization + micro fallback
- **Fingerprint full definitions**: description + schema hash, not just names
- **Provider capability gate**: tool JSON fallback only for DeepSeek
- **Abort-aware retry**: abortableDelay rejects immediately on signal

### Phase 2: Search Tools (2/2)
- **grep**: ripgrep-first with Node readline fallback, regex/literal, glob filter
- **glob**: ** recursive, * ? {,} brace, 500 cap, .gitignore-aware

### Phase 3: Dev Tools + Safety (5/5)
- **diff**: staged/unstaged, path filter, context lines
- **run_tests**: auto-detect vitest/jest/node-test, parsed failure details
- **inspect_project**: language, framework, scripts, entry files, test structure
- **repo_map**: annotated file tree with [entry]/[test]/[config]/[doc] markers
- **checkpoint/rollback**: /rollback command, rollbackToCheckpoint

### P2.1 Remaining (4/5)
- **related_tests**: source→test inference with multiple candidate paths
- **failure-classifier**: 8-class regex-based test failure diagnosis with repair suggestions
- **evidence badge**: auto-generated summary on completion (files read/modified, test results, unverified items)
- **tool output 3-layer**: raw (disk) → model (compressed) → UI (summary), integrated in bash/run_tests

### Remaining
- **benchmark task set**: 10 reproducible repo tasks (deferred)

### P2.2: Capability Reliability Layer (13/13)
- **Test baseline restored**: tsx added as devDependency
- **Path boundary enforcement**: validatePathSafe() for glob/grep/diff — rejects `..`, absolute paths outside cwd
- **Symlink cycle protection**: realpath + visited set in glob walker and grep native walker
- **Search output caps**: ripgrep streaming kill on max_results, native walker global cap
- **Checkpoint v2**: dirty snapshot at create, recordAgentTouchedFile(), rollback only agent-owned files, confirmation token
- **microCompact fix**: uses passed estimatedTokens directly instead of re-estimating
- **run_tests filter**: safe argv construction (spawn with args, no sh -c), VerificationMetadata output
- **Verification engine**: VerificationState + buildFinalVerificationReport wired into evidence badge
- **Evidence badge**: trackVerification() replaces trackTestResult(), failed/blocked tests reported
- **Raw output safety**: SHA-256 hashed filenames, no toolUseId in path
- **TUI fixes**: /verbose stale state fixed, tool flush toolName capture via toolNamesRef
- **Repo intelligence v2**: symbol-index, import-graph, context-bundle
- **Model capability routing**: ModelCapabilityCard + recommendModelForTask
- **Failure sample library**: createFailureSample with sk-* redaction
