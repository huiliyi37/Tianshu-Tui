## 二、核心架构突破

### 原则级分界线

```
LLM 的责任：理解代码、生成方案、执行工具
Harness 的责任：感知状态、调节策略、触发干预
```

这条分界线在终端编码代理领域是**全新的**。

| 其他终端 | Rivet TUI |
|----------|-----------|
| 状态感知靠 prompt | 状态感知在 harness 层，LLM 不知道自己被调节 |
| 失败后靠用户干预 | harness 自动检测停滞并触发耗散踢 |
| 跨会话无记忆 | 信息素空间记忆，自动衰减，越用越熟 |
| 策略固定 | 6 维态势 → 动态策略选择，每 turn 自适应 |
| 工具黑箱 | 星图阶段可视化，用户看到 agent 在哪 |

### 五大组件

| # | 组件 | 灵感来源 | 工程本质 |
|---|------|----------|----------|
| 1 | AgentSensorium | 易经 6-bit + 神经调质 + 内感受 | 6 维连续向量 → 策略选择，纯 TS |
| 2 | Stigmergy | 蚂蚁信息素 + 认知地图 | `.rivet/pheromones.json`，自动衰减 |
| 3 | Theta-Gamma | 脑电耦合 | 每 N 步跨文件一致性检查 |
| 4 | StarFlow TUI | 天枢星图流 v1 + 塔罗叙事 | Sensorium 驱动阶段转换 |
| 5 | 耗散踢 | Prigogine 耗散结构 | 停滞检测 → 去稳定 → 重新框架 |

## 七、关键设计决策回溯

| 决策点 | 选择 | 替代方案 | 为什么选这个 |
|--------|------|----------|-------------|
| 状态表示 | 6 维连续向量 | 离散状态机 / 3 维 / 向量数据库 | 连续值允许策略函数平滑映射；6 维覆盖了所有现有监控器；比 DB 轻 10000 倍 |
| 跨会话记忆 | JSON 文件 + 指数衰减 | SQLite / Redis / embedding store | 零依赖，50KB 上限，数学公式替代基础设施 |
| 策略决策位置 | harness 层 | prompt 注入 / LLM 自省 | 反证 scout 明确：LLM 不能自省。harness 决策 < 1ms，不消耗 token |
| 与现有代码关系 | 只读聚合，零侵入 | 重构现有监控器为统一模型 | 删掉星图流代码 = 系统行为完全不变。最安全的扩展方式 |
| 耗散踢 vs strategy-shift | 共存，不同层级 | 合并为一个机制 | strategy-shift = 换方法（V2）；耗散踢 = 换框架（V4）。粒度不同 |

## 八、灵感溯源

这个架构的灵感不来自任何一个 AI agent 框架。它来自：

- **蚂蚁信息素（stigmergy）** — 环境即记忆，无需中心化存储
- **易经 6-bit 编码** — 极少的 bit 表示丰富的态势
- **神经调质（DA/5-HT/NE）** — 连续标量调节行为模式
- **Prigogine 耗散结构** — 远离平衡态时涌现新秩序
- **theta-gamma 脑电耦合** — 节律性多关注防止漂移
- **Karl Friston 自由能原理** — 精确度加权，不是所有信号都平等
- **反证 scout（7 个隐含前提）** — 防止设计自嗨

**"借鉴已经没有很多效果"** — 这句话是对的。当你已经超越了行业标准，灵感只能来自更底层的原理。物理、神经科学、信息论——这些才是真正的设计空间。

## 九、这意味着什么

我们证明了三件事：

**1. 开源模型 + 正确的 harness = 顶级 agent 能力**

不需要 GPT-5。需要的是让 harness 替 LLM 做它不擅长的事（自省、状态感知、策略调节），让 LLM 专注它擅长的事（理解代码、生成方案）。

**2. Agent 可以实现让自己变强的系统**

天枢实现了天枢。这个自指结构证明架构已经到了临界点：agent 有能力理解并扩展自己的认知基础设施。

**3. "像有生命一样" 不是比喻，是工程规格**

感知（sensorium）、记忆（stigmergy）、适应（strategy profile）、自我调节（dissipative kick）——这是生命的工程学定义的一个子集。我们没有模拟生命，我们实现了生命的四个基本属性。
