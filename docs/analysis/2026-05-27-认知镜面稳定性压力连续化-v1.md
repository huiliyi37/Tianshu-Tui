# 认知镜面：稳定性与压力 — 从离散走向连续

> 至人之用心若镜，不将不迎，应而不藏。（庄子·应帝王）

## 背景

认知镜面（cognitive-mirror）是天枢 CVM Gen2 虚拟化层的一部分，让模型在每个回合前看到自己的认知状态。六个维度中，`stability`（稳定性）和 `pressure`（压力）长期处于"零信号"状态：

| 维度 | 旧设计 | 问题 |
|------|--------|------|
| stability | `{1.0, 0.6, 0.2}` 三元离散，基于 doom loop | 正常会话始终 1.00，退化信号不可见 |
| pressure | 上下文窗口填充率单值 | 早期会话始终 ≈0，验证债等其他压力源被忽略 |

agent 看到 `stability="1.00" pressure="0.00"` 时无法感知任何细微的会话健康变化——这面镜子在大多数时间是蒙尘的。

## 变更

### stability：四信号连续融合

**文件**：`src/agent/sensorium.ts` → `computeStability()`

```
stability = 0.40 × doomBase      // doom 等级 → {0.90, 0.50, 0.10}
          + 0.25 × predictionRate // 预测准确率（空历史 → 0.5）
          + 0.20 × diversity      // 工具多样性（空历史 → 0.5）
          + 0.15 × verificationCoverage // 已验证改动比例
```

| 场景 | 旧值 | 新值（典型） |
|------|------|------------|
| 正常会话，一切顺利 | 1.00 | 0.75–0.95 |
| 预测频繁失败 | 1.00 | 0.65–0.75 |
| 工具重复调用（疑似循环） | 1.00 | 0.70–0.82 |
| 改动未验证 | 1.00 | 0.70–0.82 |
| doom warn | 0.60 | 0.45–0.55 |
| doom blocked | 0.20 | 0.10–0.25 |

**关键收益**：正常会话中 stability 不再是常量，agent 可以看到会话健康的细微退化。

### pressure：四维多源感知

**文件**：`src/agent/sensorium.ts` → `computePressure()`

```
pressure = 0.50 × contextPressure  // 上下文窗口填充率（主导）
         + 0.30 × verificationDebt  // 未验证改动 ÷ max(文件数, 5)
         + 0.15 × cvmOverhead       // CVM 自监管开销占比
         + 0.05 × growthPenalty     // 上下文增长速度（仅正值）
```

| 场景 | 旧值 | 新值 |
|------|------|------|
| 刚启动，无改动 | 0.00 | 0.00 |
| 中期，5 文件未验证，上下文 40% | 0.40 | 0.50 |
| 上下文 70%，2 文件未验证 | 0.70 | 0.47 |
| 上下文 95%，5 文件未验证 | 0.95 | 0.78 |

**关键收益**：验证债成为压力的独立信号源。即使上下文还宽裕，堆积的未验证改动也会推高压力，促使 agent 主动验证。

## 影响范围

| 层 | 影响 | 说明 |
|----|------|------|
| `computeSensorium()` | 调用签名变更 | 向 `computePressure` 传入 `evidenceState`，向 `computeStability` 传入 `predictionAcc`、`toolCallHistory`、`evidenceState` |
| `computeStrategy()` | 阈值不变 | `stability < 0.3` 触发探索、`pressure > 0.7` 触发审慎——新值域下仍有区分度 |
| `dissipative-kick.ts` | 阈值不变 | `momentum < 0.2 && stability < 0.3` 触发耗散踢——新 stability 在 genuinely unhealthy 时才 < 0.3 |
| `applyProviderHealth()` | 行为不变 | provider 降级仍按 `stability × (1 - 0.3 × ratio)` 衰减 |

## 设计原则

1. **纯函数**：两个 compute 函数保持无副作用，输入来自已有监控数据，零 LLM 开销。
2. **向后兼容**：下游消费者（`computeStrategy`、`dissipative-kick`）的阈值未改动，新值在语义上与原三元/单值兼容。
3. **渐进式**：权重设计保留了原信号的主导地位（doom 占 stability 的 40%，context 占 pressure 的 50%），新增信号作为辅助维度避免剧烈动摇现有行为。
4. **默认中性**：当缺少数据时（如空 predictionAcc、空 toolCallHistory），默认值取 0.5，不给 agent 虚假的安全感或恐慌。

## 后续方向

- **pressure-velocity**：cognitive-mirror 中可增加 `pressure-velocity` 属性，显示 pressure 的变化速度（当前 `growthRate` 只在 `PressureResult` 中存在，未在镜面中展示）。
- **stability-trend**：同理，stability 的变化趋势（连续三回合上升/下降）可作为额外信号。
- **自适应权重**：让权重随 session 生命周期动态调整（如 genesis 期 prediction 权重更高，wuwei 期 diversity 权重更高）。
