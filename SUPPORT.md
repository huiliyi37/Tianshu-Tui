# 社区支持 · Support

## 中文

感谢使用天枢（Tianshu）。在提交 issue 或联系维护者之前，请先根据问题类型选择最合适的渠道：

### 1. 使用问题 / 配置疑问

- 先查阅 [用户手册](docs/user-guide.md) 和 [模型配置指南](docs/user-guide-provider-config.md)。
- 如果文档没有覆盖，欢迎去 [GitHub Discussions](https://github.com/huiliyi37/Tianshu-Tui/discussions) 发帖交流。

> 注意：需要先由仓库维护者在 Settings → General → Discussions 中开启 Discussions 功能。

### 2. Bug 报告 / 功能请求

- 开 Issue 前请先搜索是否已有重复或相关 Issue。
- Bug 请用 [Bug Report](https://github.com/huiliyi37/Tianshu-Tui/issues/new?template=bug_report.yml) 模板。
- 新功能请用 [Feature Request](https://github.com/huiliyi37/Tianshu-Tui/issues/new?template=feature_request.yml) 模板。

### 3. 安全漏洞

- **不要** 开公开 Issue。
- 请通过 GitHub Security → [Report a vulnerability](https://github.com/huiliyi37/Tianshu-Tui/security/advisories/new) 私密报告。
- 详见 [SECURITY.md](SECURITY.md)。

### 4. 想贡献代码

- 请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
- 大型改动建议先开 Issue 或 Discussion 讨论设计，避免返工。

### 5. 赞助

- 如果天枢对你有帮助，欢迎随缘打赏。详见 README 底部的「☕ 赞助支持」。

---

## English

Thanks for using Tianshu. Before opening an issue or reaching out to maintainers, please pick the most appropriate channel:

### 1. Usage / configuration questions

- Check the [User Guide](docs/user-guide.md) and [Provider Config Guide](docs/user-guide-provider-config.md) first.
- If the docs don't cover it, start a thread in [GitHub Discussions](https://github.com/huiliyi37/Tianshu-Tui/discussions).

> Note: a maintainer needs to enable Discussions in Settings → General → Discussions first.

### 2. Bug reports / feature requests

- Search existing issues before opening a new one.
- Use the [Bug Report](https://github.com/huiliyi37/Tianshu-Tui/issues/new?template=bug_report.yml) template for bugs.
- Use the [Feature Request](https://github.com/huiliyi37/Tianshu-Tui/issues/new?template=feature_request.yml) template for new features.

### 3. Security vulnerabilities

- **Do not** open a public issue.
- Report privately via GitHub Security → [Report a vulnerability](https://github.com/huiliyi37/Tianshu-Tui/security/advisories/new).
- See [SECURITY.md](SECURITY.md) for details.

### 4. Contributing

- Read [CONTRIBUTING.md](CONTRIBUTING.md).
- For large changes, open an Issue or Discussion first to discuss the design.

### 5. Sponsorship

- If Tianshu has been useful, voluntary donations are welcome. See the "☕ Support" section at the bottom of the README.
