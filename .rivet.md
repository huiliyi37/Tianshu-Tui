# 天枢 (Tiānshū) — Terminal Coding Agent

Node.js 22 + TypeScript strict + Ink 6 (React TUI) + DeepSeek V4 API.

## Commands

```bash
npx tsc --noEmit                                  # typecheck
npm exec -- tsx --test src/**/__tests__/*.test.ts # all tests (node:test + assert/strict)
npm run build                                      # tsup bundle
npm run dev                                        # tsup --watch
node dist/main.js                                  # launch
```

Typecheck + tests is the minimum verification after any code change.

## Code Conventions

- TypeScript strict mode, `noUncheckedIndexedAccess: true`
- No classes for data — use `interface` + plain objects
- Async/await with try-catch, never bare Promise chains
- Tools return `ToolResult { content, isError?, rawPath?, uiContent? }`
- New tools must register in `src/main.tsx` and have tests
- Test framework: `node:test` + `node:assert/strict`
- Test files mirror source: `src/agent/foo.ts` → `src/agent/__tests__/foo.test.ts`
